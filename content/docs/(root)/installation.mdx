## Prerequisites

Use a React project with [Tailwind CSS v4](https://tailwindcss.com).

## New Project Setup

Initialize a new project with the theme, every component, and visual utilities.

<Steps>

<Step>Initialize with Starter:</Step>

```bash
npx shadcn@latest init @shark/starter
```

</Steps>

## Existing Project

In an existing React project, add the theme first, then install the full catalog or only the components you need.

<Steps>

<Step>Install theme, utils, and animations:</Step>

```bash
npx shadcn@latest init @shark/style
```

<Step>Install all components at once (optional):</Step>

```bash
npx shadcn@latest add @shark/ui
```

Or install individual components from the [component docs](/docs/components).

</Steps>

## Theming

Theme tokens land with `@shark/style` or the starter. Customize them here:

1. [Styling](/docs/styling) — `globals.css`, tokens, radius, and layout
2. [Colors](/docs/colors) — neutral scales, semantic roles (`primary`, `muted`, status), and CSS variables
3. [Theme editor](/themes) — preview primary, gray, fonts, and radius without editing CSS by hand
