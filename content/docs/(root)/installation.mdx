## Prerequisites

Components are built with [Tailwind CSS v4](https://tailwindcss.com) and need it to work.

## New Project Setup

One command for a new project: theme, every component, and visual utilities.

<Steps>

<Step>Initialize with Starter:</Step>

```bash
npx shadcn@latest init @shark/starter
```

</Steps>

## Existing Project

Add the theme first, then install the full catalog or only the components you need.

<Steps>

<Step>Install theme, utils, and animations:</Step>

```bash
npx shadcn@latest init @shark/style
```

<Step>Install all components at once (optional):</Step>

```bash
npx shadcn@latest add @shark/ui
```

Or install individual components from the [component docs](/docs/components). 

</Steps>
