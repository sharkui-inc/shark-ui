Shark UI gives agents four layers of context: compact indexes for discovery, Markdown pages for implementation, a public design contract for visual fidelity, and a design handbook for rationale and extension decisions.

## Choose the task

- **Install Shark UI**: read [Foundations](/llms/foundations.txt), then [Installation](/llms/installation.txt).
- **Add a component**: read [Foundations](/llms/foundations.txt), then [Components](/llms/components.txt) and that component's Markdown page.
- **Build a form, collection, or overlay**: read [Patterns](/llms/patterns.txt) and its linked Markdown pages.
- **Migrate from another library**: use the migration section in [Patterns](/llms/patterns.txt).
- **Generate or refine UI**: read the [design contract](/design.md) before writing styles. It contains prescriptive visual rules and composition recipes.
- **Understand rationale or propose an extension**: read the [design handbook](https://github.com/sharkui-inc/shark-ui/blob/main/DESIGN.md) after the contract.

Every documentation page has a Markdown version: append `.md` to its URL. The indexes already use those URLs, so an agent can load only the context needed for the task.

## Prompt

```text
Read https://shark-ui.com/llms.txt and start with Foundations. Load only the matching task index and Markdown pages before writing code. Read https://shark-ui.com/design.md before changing UI; use the handbook when you need rationale or must propose an extension. Shark UI is a copy-and-own React registry built with Ark UI and Tailwind CSS v4; use its registry or CLI and do not use Radix UI or Base UI APIs.
```

## Skills

Use the [Shark UI Skill](/docs/skills) for durable project-level guidance. It complements current Markdown documentation with component patterns, registry workflow, and Ark UI rules; it does not replace the linked docs.
