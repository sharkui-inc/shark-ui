Shark UI publishes [llms.txt](https://llmstxt.org/) indexes so agents can find docs without crawling the site. Start at [/llms.txt](/llms.txt), then open only the index and Markdown pages that match the task.

## Choose the task

- **Install Shark UI**: [Foundations](/llms/foundations.txt), then [Installation](/llms/installation.txt).
- **Add a component**: [Foundations](/llms/foundations.txt), then [Components](/llms/components.txt) and that component's Markdown page.
- **Build a form, collection, or overlay**: [Components](/llms/components.txt) plus the relevant component Markdown pages. For form integrations, helpers, hooks, utilities, or AI Components, use [Patterns](/llms/patterns.txt).
- **Migrate from another library**: migration section in [Patterns](/llms/patterns.txt).
- **Generate or refine UI**: read the [design contract](/design.md) before writing styles.
- **Need rationale or an extension**: read the [design handbook](https://github.com/sharkui-inc/shark-ui/blob/main/DESIGN.md) after the contract.

Every docs page has a Markdown version at the same URL with `.md` appended. The indexes already link those URLs.

## Prompt

```text
Read https://shark-ui.com/llms.txt and start with Foundations. Load only the matching task index and Markdown pages before writing code. Read https://shark-ui.com/design.md before changing UI. Use the handbook when you need rationale or must propose an extension. Shark UI is a copy-and-own React registry built with Ark UI and Tailwind CSS v4. Use its registry or CLI. Do not use Radix UI or Base UI APIs.
```

## Skills

For guidance that stays with the project across sessions, install the [Shark UI Skill](/docs/skills). Docs remain the source of truth for APIs and visual rules; the skill does not replace them.
