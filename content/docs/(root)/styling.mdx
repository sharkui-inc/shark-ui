## Overview

Shark UI uses [shadcn/ui theme tokens](https://ui.shadcn.com/docs/theming#theme-tokens) plus `success`, `warning`, and `info` for status states.

## Base styles

Add the following base layer rules to `globals.css` for default document styling, selection colors, and pointer cursors on interactive elements:

<CodeCollapsibleWrapper>
```css title="globals.css"
@layer base {
  ::selection {
    @apply bg-primary/80 text-primary-foreground;
  }

  * {
    @apply border-border outline-ring/50 ring-ring;
  }

  body {
    @apply bg-background text-foreground flex min-h-svh flex-col font-sans;
  }

  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }

  html {
    @apply antialiased;
  }

  main {
    @apply flex-1 flex flex-col;
  }
}
```

## Token convention

Each color has two tokens: the base name is the **fill**. The same name with **`-foreground`** is the **text** and **icon** color meant to sit on that fill. Use both together on every new surface so content stays readable.

```tsx
<div className="bg-primary text-primary-foreground" />
```

## Adding new tokens

New variables must be wired through **`@theme inline`** as `--color-*` entries. See [Tailwind CSS](https://tailwindcss.com/docs/theme)

```css title="globals.css"
@theme inline {
  --color-brand: var(--brand);
  --color-brand-foreground: var(--brand-foreground);
}

:root {
  --brand: oklch(0.55 0.18 250);
  --brand-foreground: oklch(0.99 0 0);
}
```

## Customizing colors

Override variables on `:root` and `.dark`. Always update foreground when you change a fill.

```css title="globals.css"
:root {
  --primary: oklch(76.8% 0.233 130.85);
  --primary-foreground: oklch(98.6% 0.031 120.757);
}

.dark {
  --primary: oklch(53.2% 0.157 131.589);
  --primary-foreground: oklch(96.7% 0.067 122.328);
}
```

## Radius Scale

`--radius` is the base radius token for your theme.

We derive a small radius scale from it so components can use consistent corner sizes while still sharing a single source of truth.

```css title="app/globals.css" showLineNumbers
@theme inline {
  --radius-xs: calc(var(--radius) * 0.25);
  --radius-sm: calc(var(--radius) * 0.5);
  --radius-md: calc(var(--radius) * 0.75);
  --radius-lg: calc(var(--radius) * 1);
  --radius-xl: calc(var(--radius) * 1.5);
  --radius-2xl: calc(var(--radius) * 2);
  --radius-3xl: calc(var(--radius) * 3);
  --radius-4xl: calc(var(--radius) * 4);
}

:root {
  --radius: 0.5rem;
}
```

This means:

- `radius-lg` is the base value.
- Smaller radius scale down from `--radius`.
- Larger radius scale up from `--radius`.
- Changing `--radius` updates the entire radius scale.

### Component usage

Shark UI assigns radius by component type and visual weight:

- `rounded-sm` for compact controls: `Checkbox` and `Kbd`.
- `rounded-md` for supporting UI: `Badge` and `Skeleton`.
- `rounded-lg` for standard controls: `Button`, `Input`, `Textarea`, `Select`, `Tooltip`, and `Toast`.
- `rounded-xl` for contained surfaces: `Card`, `Menu`, `Popover`, and `HoverCard`.
- `rounded-2xl` for larger overlays: `Dialog`, `Sheet`, `Drawer`, `Command`, and `FloatingPanel`.
- `rounded-full` for circular UI and pills: `Avatar`, `Switch` and `Progress`.

Small controls use a smaller radius when needed. Nested parts inherit their container's radius so edges stay aligned.
