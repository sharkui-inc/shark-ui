Shark UI is [Ark UI](https://ark-ui.com) primitives with [shadcn](https://ui.shadcn.com)-style copy-and-own files: Tailwind defaults, variants, and a registry you install with the CLI.

The name is **sh** from shadcn and **ark** from Ark UI. **Shark**.

## Motivation

[Ark UI](https://ark-ui.com) is a headless alternative to [Radix Primitives](https://radix-ui.com/primitives) and [Base UI](https://base-ui.com). You get accessible state and parts; you still have to style them. shadcn ships styled copy-paste components. Ark's docs don't show how to pair those primitives with Tailwind or turn them into an installable design system.

## How it works

You keep component source in your repository and edit it with the rest of the app. That avoids wrapping a package, fighting its API, and chasing style overrides.

You can read every file. You change the source. Teammates and coding agents see the same implementations.
