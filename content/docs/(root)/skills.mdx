This [Agent Skills](https://agentskills.io/specification) package teaches an agent how to add, compose, style, and migrate Shark UI components in your project.

Examples of what to ask:

- _“Add a settings dialog with a form and save/cancel buttons.”_
- _“Replace this Radix dropdown with Shark Menu.”_
- _“Build a filter bar with Shark tokens that works in RTL.”_

## Install

```bash
npx skills add sharkui-inc/shark-ui
```

Open a new agent session in the repo and try a component task to confirm it loaded. If the client does not pick it up, follow the setup steps on [skills.sh](https://www.skills.sh/).

## What it helps with

### Build and compose

Pick the right component, add it with the [registry and CLI](/docs/installation), and follow its Ark UI parts. The skill covers nesting, `asChild` triggers, collections, form fields, and accessible overlays.

### Migrate and refactor

Rewrite Radix UI, Base UI, or shadcn-style code into Shark while keeping semantics and keyboard behavior. Use the [migration guides](/docs/migration) for API differences; do not treat a migration as an import rename.

### Style consistently

Reach for semantic tokens, existing variants, logical RTL-safe utilities, and documented patterns before custom CSS. For visual rules, use [Styling](/docs/styling) and the [design contract](/design.md). Use the [design handbook](https://github.com/sharkui-inc/shark-ui/blob/main/DESIGN.md) when you need rationale or want to propose an extension.

## Use it with the docs

The skill is project guidance. Published docs stay the source of truth for APIs, installation, and visual rules.

- Start at [/llms.txt](/llms.txt), then load the smallest matching index and Markdown pages.
- Before changing a component, read its Markdown page and a shipped example.
- Read [/design.md](/design.md) before generating or refining UI. Use the handbook for rationale or extension decisions.
- Shark UI is React, Ark UI, and Tailwind CSS v4. Do not swap in Radix UI or Base UI APIs.

## Keeping it current

Reinstall the skill when you update the library or spot a mismatch. If the skill and docs disagree, follow the docs and report it in the [repository](https://github.com/sharkui-inc/shark-ui).

## Compatibility

Works with agents that support the Agent Skills format. Client support differs; see the list and setup notes on [skills.sh](https://www.skills.sh/).
