[Radix Primitives](https://radix-ui.com/primitives) and [Ark UI](https://ark-ui.com) solve the same problem: accessible headless behavior you style yourself.

> Shark UI wraps Ark with Tailwind defaults and a copy-and-own install flow.

## What changes

| Radix | Shark |
| --- | --- |
| Select items mapped from children | Ark `collection`. `defaultValue` is a string array |
| `type="single"` and a string value on Toggle Group | Value array. Shark `multiple` defaults to `true` |
| `type="single"` string, or `type="multiple"` array, on Accordion | Always a value array. Shark `collapsible` defaults to `true` |
| `@radix-ui/react-dropdown-menu` | [Menu](/docs/components/menu) |
| Separate primitive imports per package | One Shark component per feature area |

## Component equivalents

| Radix Primitive | Shark UI |
| --- | --- |
| Dropdown Menu | [Menu](/docs/components/menu) |
| Label | [Field](/docs/components/field) |

Browse [Components](/docs/components) for same-name primitives (Dialog, Select, Tabs, and others).

## Triggers

`Open` sits inside the single `asChild` child.

```tsx title="Radix UI" showLineNumbers
import * as DropdownMenu from "@radix-ui/react-dropdown-menu";

<DropdownMenu.Root>
  <DropdownMenu.Trigger asChild>
    <button type="button">Open</button>
  </DropdownMenu.Trigger>
</DropdownMenu.Root>
```

`Open` sits inside the single `asChild` child.

```tsx title="Shark UI" showLineNumbers
import { Menu, MenuTrigger } from "@/components/ui/menu";
import { Button } from "@/components/ui/button";

<Menu>
  <MenuTrigger asChild>
    <Button variant="outline">Open</Button>
  </MenuTrigger>
</Menu>;
```

## Select

Items are children. `defaultValue` is a string.

```tsx title="Radix UI" showLineNumbers
import * as Select from "@radix-ui/react-select";

<Select.Root defaultValue="next">
  <Select.Trigger>
    <Select.Value placeholder="Framework" />
  </Select.Trigger>
  <Select.Content>
    <Select.Item value="next">Next.js</Select.Item>
    <Select.Item value="vite">Vite</Select.Item>
  </Select.Content>
</Select.Root>
```

`collection`. `defaultValue` is `string[]`.

```tsx title="Shark UI" showLineNumbers
import { createListCollection } from "@ark-ui/react";
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select";

const frameworks = createListCollection({
  items: ["Next.js", "Vite"],
});

<Select collection={frameworks} defaultValue={["Next.js"]}>
  <SelectTrigger>
    <SelectValue placeholder="Framework" />
  </SelectTrigger>
  <SelectContent>
    {frameworks.items.map((item) => (
      <SelectItem item={item} key={item}>
        {item}
      </SelectItem>
    ))}
  </SelectContent>
</Select>;
```

## Toggle Group

`type="single"` is a string. `type="multiple"` is a string array.

```tsx title="Radix UI" showLineNumbers
import * as ToggleGroup from "@radix-ui/react-toggle-group";

<ToggleGroup.Root type="single" defaultValue="daily">
  <ToggleGroup.Item value="daily">Daily</ToggleGroup.Item>
</ToggleGroup.Root>
```

Always a string array. `multiple` defaults to `true`.

```tsx title="Shark UI" showLineNumbers
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group";

<ToggleGroup defaultValue={["daily"]} multiple={false}>
  <ToggleGroupItem value="daily">Daily</ToggleGroupItem>
</ToggleGroup>;
```

## Accordion

`type="single"` is a string. `type="multiple"` is a string array. `collapsible` is opt-in.

```tsx title="Radix UI" showLineNumbers
import * as Accordion from "@radix-ui/react-accordion";

<Accordion.Root type="single" collapsible defaultValue="details">
  <Accordion.Item value="details">...</Accordion.Item>
</Accordion.Root>
```

Always a string array. `collapsible` defaults to `true`.

```tsx title="Shark UI" showLineNumbers
import { Accordion, AccordionItem } from "@/components/ui/accordion";

<Accordion defaultValue={["details"]}>
  <AccordionItem value="details">...</AccordionItem>
</Accordion>;
```

## Theming

Radix ships unstyled. Map your CSS variables to Shark tokens. See [Colors](/docs/colors) and [Styling](/docs/styling).

## Checklist

- Replace `@radix-ui/react-*` imports with Shark components from the docs.
- Add collections where list primitives require them.
- Re-check controlled values; do not assume Radix string shapes.
- Keep overlay titles and control labels accessible.
- Use logical spacing for [RTL](/docs/rtl).

Older shadcn projects created with `radix` share these primitive differences. Current shadcn defaults to [Base UI](/docs/migration/base-ui).
