## Usage

```tsx
import { FocusTrap } from "@/components/ui/focus-trap";
```

```tsx
<FocusTrap disabled={!active}>
  <Input aria-label="Name" type="text" />
  <Button onClick={endTrap}>End trap</Button>
</FocusTrap>
```

## API Reference

### FocusTrap

| Prop | Type | Default |
| --- | --- | --- |
| `disabled` | `boolean` | `-` |
| `asChild` | `boolean` | `-` |
| `initialFocus` | `FocusTargetOrFalse` | `-` |
| `fallbackFocus` | `FocusTarget` | `-` |
| `returnFocusOnDeactivate` | `boolean` | `true` |
| `setReturnFocus` | `FocusTargetValueOrFalse \| ((node: HTMLElement \| SVGElement) => FocusTargetValueOrFalse)` | `-` |
| `persistentElements` | `(() => Element \| null)[]` | `-` |
| `onActivate` | `() => void` | `-` |
| `onDeactivate` | `() => void` | `-` |

For a complete list of props, see the [Ark UI documentation](https://ark-ui.com/docs/utilities/focus-trap#api-reference).
