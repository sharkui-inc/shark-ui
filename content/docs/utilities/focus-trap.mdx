## Usage

```tsx
import { FocusTrap } from "@/components/ui/focus-trap";
```

```tsx
<FocusTrap disabled={!active}>
  <Input aria-label="Name" type="text" />
  <Button onClick={endTrap}>End trap</Button>
</FocusTrap>
```

The wrapper has no visual styles. Use `className` to lay out the container, or `asChild` with a single element. Always provide a way to end the trap from inside it. Existing Shark dialogs and drawers already manage focus; they do not need an additional trap.

## API Reference

### FocusTrap

Accepts Ark's `FocusTrap` props, native div attributes, and a ref.

| Prop | Type | Description |
| --- | --- | --- |
| `disabled` | `boolean` | Disable the trap. The examples start disabled. |
| `asChild` | `boolean` | Merge onto a single child element. |
| `initialFocus` | Focus target or function; also accepts `false` | Choose initial focus, or skip it. |
| `fallbackFocus` | Focus target or function | Target to focus if no tabbable controls exist. Give a fallback container `tabIndex={-1}`. |
| `returnFocusOnDeactivate` | `boolean` | Return focus after deactivation; defaults to `true`. The basic example explicitly sets it to `false`. |
| `setReturnFocus` | Focus target or function | Choose the target for restored focus. |
| `persistentElements` | `(() => Element \| null)[]` | Additional elements, such as portalled content, treated as inside the trap. |
| `onActivate`, `onDeactivate` | `() => void` | Callbacks when the trap activates or deactivates. |
