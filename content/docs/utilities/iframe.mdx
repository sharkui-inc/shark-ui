## Usage

```tsx
import { Iframe } from "@/components/ui/iframe";
```

```tsx
<Iframe style={{ height: "var(--height)", width: "100%" }} title="Preview">
  <p>This content is rendered inside the iframe.</p>
</Iframe>
```

## What goes into the `<Iframe>`

- `children`: rendered into `.frame-root`, or `<body>` if `.frame-root` is missing.
- `head`: rendered into the iframe `<head>`.
- `srcDoc`: the iframe's initial HTML. Changing it rewrites the document and remounts `children`.
- `onMount`: after `children` mount. Inject scripts through `contentDocument`.
- `onUnmount`: as `children` unmount. Undo `onMount`.
- Native iframe attributes (`title`, `sandbox`, `allow`, `loading`, `className`, `style`): on the outer `<iframe>`.

## API Reference

### Iframe

Accepts native iframe attributes and a ref.

| Prop | Type | Description |
| --- | --- | --- |
| `head` | `ReactNode` | Rendered into the iframe `<head>`. |
| `onMount` | `() => void` | After `children` mount. Inject scripts through `contentDocument`. |
| `onUnmount` | `() => void` | As `children` unmount. Undo `onMount`. |
| `srcDoc` | `string` | Initial HTML. Changing it rewrites the document and remounts `children`. |
| `title` | `string` | Accessible name of the outer iframe. Defaults to `frame:<id>`. |
| `sandbox` | `string` | Space-separated tokens that restrict the iframe. |
| `allow` | `string` | Permissions policy for the iframe. |
| `loading` | `"eager" \| "lazy"` | Load immediately or lazily. |
| `className` | `string` | Classes on the outer iframe. |

---

For a complete list of props, see the [Ark UI documentation](https://ark-ui.com/docs/utilities/frame#api-reference).
