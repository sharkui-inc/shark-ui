## Usage

```tsx
import React from "react";
import { Presence } from "@/registry/react/components/presence";

const [visible, setVisible] = React.useState(false);

<Presence present={visible}>
  Content that animates in and out
</Presence>
```

## Lazy

Setting `lazyMount` and `unmountOnExit` to `true` lazy mounts and unmounts the content.

It will remove the element from the DOM when it is not present. Shark defaults both to `true`.

```tsx showLineNumbers
<Presence lazyMount unmountOnExit {...}>
  {/** content */}
</Presence>
```

## Hide mode

When content stays mounted after close, `hideMode` chooses how it is hidden:

- `'display-none'` (default): HTML `hidden`. Effects stay alive.
- `'activity'`: React 19 Activity. Effects pause.

`hideMode` does nothing when `unmountOnExit` is `true`, because the tree is removed on close.

```tsx
<Presence present={visible} unmountOnExit={false} hideMode="activity">
  {/** content */}
</Presence>
```

The same prop is available on overlays that keep content mounted (Dialog, Drawer, Sheet, Accordion, Collapsible, Tree View). Shark overlays default `unmountOnExit`, so set `unmountOnExit={false}` if you want `hideMode` to apply.

`onEnterComplete` fires once the enter animation finishes, matching `onExitComplete`.

## States

Presence automatically manages the attribute `data-state` to `open` and `closed`. This enables styling and animations based on visibility state.


```tsx showLineNumbers
<Presence present={true} /> // <div data-state="open" />
<Presence present={false} /> // <div data-state="closed" />
```

## API Reference

### Presence

| Prop | Type | Default |
| --- | --- | --- |
| `present` | `boolean` | `false` |
| `unmountOnExit` | `boolean` | `true` |
| `lazyMount` | `boolean` | `true` |
| `hideMode` | `"display-none" \| "activity"` | `"display-none"` |
| `onEnterComplete` | `() => void` | - |
| `onExitComplete` | `() => void` | - |
| `asChild` | `boolean` | `false` |

---

For a complete list of props, see the [Ark UI documentation](https://ark-ui.com/docs/utilities/presence#api-reference).
