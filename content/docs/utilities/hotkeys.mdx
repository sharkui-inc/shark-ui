## Usage

```tsx
import { useFormatHotkey, useHotkey } from "@/components/ui/hotkeys";
```

```tsx
const formatHotkey = useFormatHotkey()

useHotkey({
  hotkey: "mod+K",
  action: () => setOpen(true),
})

return <kbd>{formatHotkey("mod+K")}</kbd>
```

## API Reference

### createHotkeyStore

| Prop | Type | Default |
| --- | --- | --- |
| `activeScopes` | `string \| string[]` | `["*"]` |
| `conflictBehavior` | `"warn" \| "error" \| "replace" \| "allow"` | `"warn"` |
| `defaultOptions` | `HotkeyOptions` | - |
| `sequenceTimeoutMs` | `number` | `1000` |

### useHotkey

Registers one command. Takes every field of `UseHotkeysCommand`, plus an optional `store`.

### useHotkeys

| Prop | Type | Default |
| --- | --- | --- |
| `commands` | `UseHotkeysCommand[]` | - |
| `store` | `HotkeyStore` | shared default store |
| `id` | `string` | generated |

### UseHotkeysCommand

| Prop | Type | Default |
| --- | --- | --- |
| `id` | `string` | generated |
| `hotkey` | `string` | - |
| `action` | `(event: KeyboardEvent) => void` | - |
| `label` | `string` | - |
| `description` | `string` | - |
| `category` | `string` | - |
| `keywords` | `string[]` | - |
| `scopes` | `string \| string[]` | `"*"` |
| `enabled` | `boolean \| (() => boolean)` | `true` |
| `options` | `HotkeyOptions` | - |

### HotkeyOptions

| Prop | Type | Default |
| --- | --- | --- |
| `preventDefault` | `boolean` | - |
| `stopPropagation` | `boolean` | - |
| `enableOnFormTags` | `boolean \| ("input" \| "textarea" \| "select")[]` | `false` |
| `enableOnContentEditable` | `boolean` | `false` |
| `capture` | `boolean` | `true` |
| `requireReset` | `boolean` | `false` |
| `eventType` | `"keydown" \| "keyup"` | `"keydown"` |
| `target` | `Element \| (() => Element \| null)` | - |

### useHotkeyRegistrations

Returns every command currently registered on the store, with its `label`, `category`, `keywords` and resolved hotkey.

### useHotkeyStore

Returns the store you passed, or the shared default store. Use `setScope`, `addScope`, `removeScope` and `toggleScope` to change which commands are live, and `isPressed` to test a combination directly.

### usePressedKeys

Returns the keys currently held down.

### useIsKeyPressed

| Prop | Type | Default |
| --- | --- | --- |
| `hotkey` | `string` | - |
| `store` | `HotkeyStore` | shared default store |

### usePlatform

Returns `'mac'`, `'windows'` or `'linux'`. Resolves after mount, so server and client render the same markup.

### useFormatHotkey

Returns `(hotkey: string, options?: HotkeyFormatOptions) => string`. Prefer this over importing `formatHotkey` directly inside a component.

### useHotkeyRecorder

| Prop | Type | Default |
| --- | --- | --- |
| `onRecord` | `(hotkey: RecordedHotkey) => void` | - |
| `onCancel` | `() => void` | - |
| `onClear` | `() => void` | - |
| `formatOptions` | `HotkeyFormatOptions` | - |
| `sequenceTimeoutMs` | `number` | - |

Returns `{ recording, value, start, stop, cancel, clear }`.

For a complete list of props, see the [Ark UI documentation](https://ark-ui.com/docs/utilities/hotkeys#api-reference).
