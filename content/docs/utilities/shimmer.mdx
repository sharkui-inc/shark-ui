## Installation

The `shimmer` utility is included when you initialize Shark UI styles:

```bash
pnpm dlx shadcn@latest init @shark/style
```

The CLI adds the utility to the Tailwind CSS file configured in `components.json`.

## Usage

Add `shimmer` to a text element to animate a highlight across the text.

```tsx
<p className="shimmer text-muted-foreground">Generating response&hellip;</p>
```

The highlight is derived from `currentColor`, so it adapts to the text color and automatically brightens in dark mode.

## API Reference

| Class | Effect |
| --- | --- |
| `shimmer` | Animate a highlight across text |
| `shimmer-once` | Run the animation once |
| `shimmer-reverse` | Reverse animation direction |
| `shimmer-none` | Disable the effect and restore text color |
| `shimmer-color-*` | Set highlight color and optional opacity |
| `shimmer-duration-*` | Set duration in milliseconds |
| `shimmer-spread-*` | Set highlight width |
| `shimmer-angle-*` | Set highlight angle |

The sweep follows reading direction and reverses automatically in RTL. When reduced motion is enabled, the animation and highlight are disabled and the text renders normally.
