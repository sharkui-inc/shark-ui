## Usage

```tsx
import {
  Reasoning,
  ReasoningContent,
  ReasoningTrigger,
} from "@/components/ui/reasoning";
```

```tsx
<Reasoning duration={8}>
  <ReasoningTrigger duration={8} />
  <ReasoningContent>The helper already checks empty fields...</ReasoningContent>
</Reasoning>
```

Place reasoning above the assistant [Message Bubble](/docs/ai-elements/message-bubble) inside [Message](/docs/ai-elements/message).

## API Reference

### Reasoning

Root collapsible. `defaultOpen` follows `isStreaming` when unset.

| Prop | Type | Default |
| --- | --- | --- |
| `duration` | `number` | `-` |
| `isStreaming` | `boolean` | `false` |
| `className` | `string` | `-` |

### ReasoningTrigger

Toggles the reasoning. Default label is `Thought`, `Thinking` while streaming, or `Thought for {duration}s`.

| Prop | Type | Default |
| --- | --- | --- |
| `duration` | `number` | `-` |
| `isStreaming` | `boolean` | `false` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### ReasoningContent

Holds the reasoning text.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
