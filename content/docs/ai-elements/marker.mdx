## API Reference

### Marker

Root status line, bordered row, or labeled separator.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "separator" \| "border"` | `"default"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### MarkerIcon

Decorative icon slot.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### MarkerContent

Label text for the marker.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
