## Usage

```tsx
import {
  Diff,
  DiffContent,
  DiffHeader,
  DiffLine,
  DiffStats,
} from "@/components/ui/diff";
```

```tsx
<Diff>
  <DiffHeader title="src/auth.ts">
    <DiffStats added={4} removed={1} />
  </DiffHeader>
  <DiffContent>
    <DiffLine line={13} type="delete">  return localStorage.token;</DiffLine>
    <DiffLine line={13} type="add">  const t = cookies.get("session");</DiffLine>
  </DiffContent>
</Diff>
```

## Visual consistency

`Diff` and [Code Block](/docs/ai-elements/code-block) use the same technical surface: a 36px header, 14px interface text, a scrollable viewport, and 14px / 24px code metrics. They remain separate components: the Diff gutter always shows right-aligned line numbers, while `CodeBlock` prioritizes syntax highlighting and optional line numbers.

## Title

`DiffHeader` supports two title patterns:

### Using props

Pass the `title` prop directly to `DiffHeader`.

```tsx showLineNumbers
<DiffHeader title="src/auth.ts">
  <DiffStats added={4} removed={1} />
</DiffHeader>
```

> This approach does not require the `DiffFile` component.

### Using components

Use `DiffFile` as a child for more control.

```tsx showLineNumbers
<DiffHeader>
  <DiffFile>src/auth.ts</DiffFile>
  <DiffStats added={4} removed={1} />
</DiffHeader>
```

## API Reference

### Diff

Root panel for a unified diff.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### DiffHeader

Header for the file path and stats. Pass `title` to render `DiffFile`. A string
child is wrapped the same way.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | `-` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### DiffFile

File path. Rendered automatically when `title` is set on `DiffHeader`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### DiffAction

Trailing header actions. Aligns to the end.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### DiffStats

Added and removed counts.

| Prop | Type | Default |
| --- | --- | --- |
| `added` | `number` | `0` |
| `removed` | `number` | `0` |
| `aria-label` | `string` | `"{added} added, {removed} removed"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### DiffContent

Scrollable hunk. Right-aligned line numbers sit in a sticky gutter on horizontal overflow.

| Prop | Type | Default |
| --- | --- | --- |
| `dir` | `"ltr" \| "rtl"` | `"ltr"` |
| `className` | `string` | `-` |

### DiffLine

A source line. Children are the line text. Add and delete states come from `type`.

| Prop | Type | Default |
| --- | --- | --- |
| `type` | `"add" \| "delete" \| "context"` | `"context"` |
| `line` | `number \| null` | `-` |
| `aria-label` | `string` | From `type` and `line` |
| `className` | `string` | `-` |
