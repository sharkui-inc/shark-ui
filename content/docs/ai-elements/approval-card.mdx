## Title

`ApprovalCardHeader` supports two title patterns:

### Using props

Pass the `title` prop directly to `ApprovalCardHeader`.

```tsx showLineNumbers
<ApprovalCardHeader title="Apply the staging migration?">
  <TerminalIcon aria-hidden="true" />
  <ApprovalCardAction>
    <ApprovalCardProgress />
  </ApprovalCardAction>
</ApprovalCardHeader>
```

> This approach does not require the `ApprovalCardTitle` component.

### Using components

Use `ApprovalCardTitle` as a child for more control.

```tsx showLineNumbers
<ApprovalCardHeader>
  <TerminalIcon aria-hidden="true" />
  <ApprovalCardTitle>Apply the staging migration?</ApprovalCardTitle>
  <ApprovalCardAction>
    <ApprovalCardProgress />
  </ApprovalCardAction>
</ApprovalCardHeader>
```
