## Usage

```tsx
import {
  CodeBlock,
  CodeBlockActions,
  CodeBlockContent,
  CodeBlockCopy,
  CodeBlockHeader,
} from "@/components/ui/code-block";
```

```tsx
<CodeBlock className="max-h-80" code={source}>
  <CodeBlockHeader title="helpers.ts">
    <CodeBlockActions>
      <CodeBlockCopy />
    </CodeBlockActions>
  </CodeBlockHeader>
  <CodeBlockContent highlightedLines={[2]} showLineNumbers />
</CodeBlock>
```

## Title

`CodeBlockHeader` supports two title patterns:

### Using props

Pass the `title` prop directly to `CodeBlockHeader`.

```tsx showLineNumbers
<CodeBlockHeader title="helpers.ts">
  <CodeBlockActions>
    <CodeBlockCopy />
  </CodeBlockActions>
</CodeBlockHeader>
```

> This approach does not require the `CodeBlockTitle` component.

### Using components

Use `CodeBlockTitle` as a child for more control.

```tsx showLineNumbers
<CodeBlockHeader>
  <CodeBlockTitle>helpers.ts</CodeBlockTitle>
  <CodeBlockActions>
    <CodeBlockCopy />
  </CodeBlockActions>
</CodeBlockHeader>
```

## Streaming

Set `isStreaming` while an AI response is still appending code. The component renders the newest text immediately, refreshes syntax highlighting at a controlled cadence while the response grows, and highlights the final snippet as soon as streaming completes.

```tsx
<CodeBlock
  className="max-h-80"
  code={partialCode}
  isStreaming={status === "streaming"}
  language="tsx"
>
  <CodeBlockContent showLineNumbers />
</CodeBlock>
```

This is a client component. A Server Component can pass its serializable `code`, `language`, and `isStreaming` values to it, but live streamed code is highlighted in the browser. Static server-rendered highlighting is intentionally outside this component's API.

## Visual consistency

`CodeBlock` and [Diff](/docs/ai-elements/diff) share the same technical surface: a 36px header, 14px interface text, a scrollable viewport, and 14px / 24px code metrics. They remain separate components because syntax highlighting, optional line numbers, and copy actions serve a different purpose from add/remove states.

## API Reference

### CodeBlock

Root panel. Provides `code`, `language`, and streaming state to its parts.

| Prop | Type | Default |
| --- | --- | --- |
| `code` | `string` | `""` |
| `language` | `CodeBlockLanguage` | `"tsx"` |
| `isStreaming` | `boolean` | `false` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### CodeBlockHeader

Optional header for titles and actions. Pass `title` to render `CodeBlockTitle`.
A string child is wrapped the same way.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | `-` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### CodeBlockTitle

Title text for the code block. Rendered automatically when `title` is set on
`CodeBlockHeader`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### CodeBlockFilename

Optional truncated filename when composing a custom title.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### CodeBlockActions

Right-aligned optional actions container.

### CodeBlockCopy

Copies `code` from `CodeBlock`.

| Prop | Type | Default |
| --- | --- | --- |
| `timeout` | `number` | `2000` |
| `className` | `string` | `-` |

### CodeBlockContent

Renders the root `code` or a string child with Shiki syntax highlighting.

| Prop | Type | Default |
| --- | --- | --- |
| `showLineNumbers` | `boolean` | `false` |
| `highlightedLines` | `number[]` | `[]` |
| `code` | `string` | root `code` |
| `language` | `CodeBlockLanguage` | root `language` |
| `isStreaming` | `boolean` | root `isStreaming` |
| `className` | `string` | `-` |

### Language selector parts

`CodeBlockLanguageSelector`, `CodeBlockLanguageSelectorTrigger`, `CodeBlockLanguageSelectorValue`, `CodeBlockLanguageSelectorContent`, and `CodeBlockLanguageSelectorItem` are styled wrappers around [Select](/docs/components/select). Provide the Select collection and control its value from the consuming composition.

`CodeBlockLanguage` accepts every bundled Shiki language and `"text"` for
plain, unhighlighted content.
