## Anatomy

```text
Queue
└── QueueSection
    ├── QueueSectionHeader
    │   ├── QueueTitle
    │   └── QueueSectionAction
    └── QueueSectionContent
        └── QueueList
            └── QueueItem
                ├── QueueItemContent
                └── QueueItemActions
                    └── QueueItemAction
```

## Usage

```tsx
import {
  Queue,
  QueueItem,
  QueueItemAction,
  QueueItemActions,
  QueueItemContent,
  QueueList,
  QueueSection,
  QueueSectionAction,
  QueueSectionContent,
  QueueSectionHeader,
  QueueTitle,

```

## API Reference

### Queue

Root container for prompt sections.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### QueueSection

Bounded panel for one queue group.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### QueueSectionHeader

Toolbar row for the section title and actions.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | `-` |
| `className` | `string` | `-` |

### QueueTitle

Section title. Rendered automatically when `title` is set on `QueueSectionHeader`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### QueueSectionAction

Trailing header actions.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### QueueSectionContent

Holds the list of queued items.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### QueueList

List of queued items.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### QueueItem

A single queued prompt row.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### QueueItemContent

Prompt text. Strikes through when `completed` is true.

| Prop | Type | Default |
| --- | --- | --- |
| `completed` | `boolean` | `false` |
| `className` | `string` | `-` |

### QueueItemActions

Container for row actions.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### QueueItemAction

Ghost button for a row or header action. Row actions fade in on hover.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "link" \| "destructive"` | `"ghost"` |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl" \| "icon-xs" \| "icon-sm" \| "icon-md" \| "icon-lg" \| "icon-xl"` | `"icon-xs"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
