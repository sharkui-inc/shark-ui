## Usage

```tsx
import {
  Context,
  ContextBody,
  ContextContent,
  ContextFooter,
  ContextHeader,
  ContextMeter,
  ContextTitle,
  ContextTrigger,
  ContextUsageRow,
} from "@/components/ui/context";
```

```tsx
<Context maxTokens={128000} usedTokens={18420} costLabel="$0.042">
  <ContextTrigger />
  <ContextContent>
    <ContextHeader title="Context Usage">
      <ContextMeter />
    </ContextHeader>
    <ContextBody>
      <ContextUsageRow title="Input" value={4200} />
      <ContextUsageRow title="Output" value={860} />
    </ContextBody>
    <ContextFooter />
  </ContextContent>
</Context>
```

## Title

`ContextHeader` supports two title patterns:

### Using props

Pass the `title` prop directly to `ContextHeader`.

```tsx showLineNumbers
<ContextHeader title="Context Usage">
  <ContextMeter />
</ContextHeader>
```

> This approach does not require the `ContextTitle` component.

### Using components

Use `ContextTitle` as a child when you need more control, such as a close
button.

```tsx showLineNumbers
<ContextHeader>
  <ContextTitle showCloseButton>Context Usage</ContextTitle>
  <ContextMeter />
</ContextHeader>
```

## API Reference

### Context

Root [Popover](/docs/components/popover). Provides token usage to child parts.

| Prop | Type | Default |
| --- | --- | --- |
| `usedTokens` | `number` | **required** |
| `maxTokens` | `number` | **required** |
| `costLabel` | `string` | `-` |
| `className` | `string` | `-` |

### ContextTrigger

Opens the popover on click. Default children are a usage ring and percent label.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `-` |
| `className` | `string` | `-` |

### ContextIcon

Displays context usage as a circular progress icon.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### ContextContent

Holds the usage panel. Forwards [PopoverContent](/docs/components/popover) props.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `-` |

### ContextHeader

Layout container for `ContextTitle` and `ContextMeter`.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | `-` |
| `className` | `string` | `-` |

### ContextTitle

Title for the context panel.

| Prop | Type | Default |
| --- | --- | --- |
| `showCloseButton` | `boolean` | `false` |
| `className` | `string` | `-` |

### ContextMeter

Displays the percentage, token count, and progress bar.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### ContextBody

Body for token breakdown rows.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### ContextFooter

Footer with total cost. Children replace the default `costLabel` row.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### ContextUsageRow

Usage row with a user-defined title and value.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | **required** |
| `value` | `number` | **required** |
| `className` | `string` | `-` |
