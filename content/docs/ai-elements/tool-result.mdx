## Anatomy

```text
ToolResult
├── ToolResultTrigger
│   ├── ToolResultTitle
│   ├── ToolResultMeta
│   ├── ToolResultName
│   └── ToolResultAction
│       ├── ToolResultStatus (optional)
│       └── CollapsibleIndicator (optional)
└── ToolResultContent
```

## Usage

```tsx
import {
  ToolResult,
  ToolResultAction,
  ToolResultContent,
  ToolResultMeta,
  ToolResultName,
  ToolResultStatus,
  ToolResultTitle,
  ToolResultTrigger,
} from "@/components/ui/tool-result";
```

```tsx
<ToolResult status="success">
  <ToolResultTrigger>
    <ToolResultTitle>Tests passed</ToolResultTitle>
    <ToolResultMeta>2.9s</ToolResultMeta>
    <ToolResultName>terminal.run</ToolResultName>
    <ToolResultAction>
      <ToolResultStatus />
    </ToolResultAction>
  </ToolResultTrigger>
  <ToolResultContent />
</ToolResult>
```

## API Reference

### ToolResult

Root [Collapsible](/docs/components/collapsible). `aria-busy` is set while `status` is `"running"`. `defaultOpen` is `true` when `status` is `"running"`.

| Prop | Type | Default |
| --- | --- | --- |
| `status` | `"running" \| "success" \| "error" \| "cancelled"` | `"success"` |
| `defaultOpen` | `boolean` | `true` when `status` is `"running"` |
| `className` | `string` | `-` |

### ToolResultTrigger

Toggles the result. Place `ToolResultAction` inside to align trailing content and the optional chevron at the logical end.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### ToolResultAction

Trailing action area. It follows the document direction: aligned at the end in LTR and RTL. Set `showTrigger` to `false` to hide its chevron.

| Prop | Type | Default |
| --- | --- | --- |
| `showTrigger` | `boolean` | `true` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### ToolResultTitle

Primary label in the trigger.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### ToolResultMeta

Secondary text such as duration.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### ToolResultName

Tool name in the trigger.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### ToolResultStatus

Optional status icon and label. Render it inside `ToolResultAction`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

| Status | Label |
| --- | --- |
| `running` | Running |
| `success` | Completed |
| `error` | Failed |
| `cancelled` | Cancelled |

### ToolResultContent

Content of the tool result.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
