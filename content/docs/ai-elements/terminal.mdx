## Anatomy

```text
Terminal
├── TerminalHeader
│   ├── TerminalTitle
│   └── TerminalAction
└── TerminalContent
```

## Usage

```tsx
import { Terminal, TerminalContent, TerminalHeader } from "@/components/ui/terminal";
```

```tsx
<Terminal output={"\u001B[32m✓\u001B[0m All tests passed"}>
  <TerminalHeader>zsh · pnpm test</TerminalHeader>
  <TerminalContent />
</Terminal>
```

## API Reference

### Terminal

Root panel.

| Prop | Type | Default |
| --- | --- | --- |
| `output` | `string` | `""` |
| `autoScroll` | `boolean` | `true` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### TerminalHeader

Header for the session label and actions. Pass `title` to render
`TerminalTitle`. A string child is wrapped the same way.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | `-` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### TerminalTitle

Session label. Rendered automatically when `title` is set on `TerminalHeader`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### TerminalAction

Container for header actions. Aligns to the end.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### TerminalContent

Renders parsed ANSI `output`. Children replace parsed tokens.

| Prop | Type | Default |
| --- | --- | --- |
| `output` | `string` | `Terminal` `output` |
| `children` | `React.ReactNode` | `-` |
| `className` | `string` | `-` |

### toPlainOutput

Returns the visible text with ANSI SGR codes removed.
