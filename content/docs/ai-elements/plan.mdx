## Usage

```tsx
import {
  Plan,
  PlanAction,
  PlanContent,
  PlanHeader,
  PlanItem,
  PlanItemContent,
  PlanItemDetail,
  PlanItemDetailFile,
  PlanItemTrigger,
  PlanTitle,
  PlanTrigger,
} from "@/components/ui/plan";
```

```tsx
<Plan completed={1} total={3}>
  <PlanHeader title="Add email validation">
    <PlanAction>
      <PlanTrigger />
    </PlanAction>
  </PlanHeader>
  <PlanContent>
    <PlanItem status="in-progress">
      <PlanItemTrigger title="Patch isValidEmail" />
      <PlanItemContent>
        <PlanItemDetail>
          Updating <PlanItemDetailFile>src/utils/helpers.ts</PlanItemDetailFile>
        </PlanItemDetail>
      </PlanItemContent>
    </PlanItem>
  </PlanContent>
</Plan>
```

## Title

`PlanHeader` supports two title patterns:

### Using props

Pass the `title` prop directly to `PlanHeader`.

```tsx showLineNumbers
<PlanHeader title="Add email validation">
  <PlanAction>
    <PlanTrigger />
  </PlanAction>
</PlanHeader>
```

> This approach does not require the `PlanTitle` component.

### Using components

Use `PlanTitle` as a child for more control.

```tsx showLineNumbers
<PlanHeader>
  <PlanTitle>Add email validation</PlanTitle>
  <PlanAction>
    <PlanTrigger />
  </PlanAction>
</PlanHeader>
```

## API Reference

### Plan

Root collapsible. Forwards [Collapsible](/docs/components/collapsible) props and can show overall progress.

| Prop | Type | Default |
| --- | --- | --- |
| `defaultOpen` | `boolean` | `true` |
| `completed` | `number` | `-` |
| `total` | `number` | `-` |
| `className` | `string` | `-` |

### PlanHeader

Header area for the title and actions. Pass `title` to render `PlanTitle`. A
string child is wrapped the same way.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | `-` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanTitle

Title text for the plan. Rendered automatically when `title` is set on
`PlanHeader`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanAction

Container for the collapse trigger. Aligns to the end.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanTrigger

Toggles the plan. Default children are the collapsible indicator.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanContent

Holds nested plan items.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanItem

A collapsible unit of work with a status and optional details.

| Prop | Type | Default |
| --- | --- | --- |
| `status` | `"pending" \| "in-progress" \| "completed" \| "error"` | `"pending"` |
| `className` | `string` | `-` |

### PlanItemTrigger

Toggles the item and, by default, displays its status, title, and indicator.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | **required** |
| `status` | `"pending" \| "in-progress" \| "completed" \| "error"` | inherits `PlanItem` status |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanItemContent

Contains the details revealed when the item is open.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanItemDetail

A supporting line for progress, context, files, or custom content.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanItemDetailFile

A compact file reference for use inside a plan item detail.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "secondary" \| "outline" \| "success" \| "info" \| "warning" \| "destructive"` | `"outline"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
