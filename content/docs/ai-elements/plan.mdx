## Usage

```tsx
import {
  Plan,
  PlanContent,
  PlanHeader,
  PlanItem,
  PlanItemContent,
  PlanItemDetail,
  PlanItemDetailFile,
  PlanItemTrigger,
  PlanProgress,
  PlanTitle,
} from "@/components/ui/plan";
```

```tsx
<Plan>
  <PlanHeader title="Add email validation" />
  <PlanContent>
    <PlanItem collapsible status="in-progress">
      <PlanItemTrigger title="Patch isValidEmail" />
      <PlanItemContent>
        <PlanItemDetail>
          Updating <PlanItemDetailFile>src/utils/helpers.ts</PlanItemDetailFile>
        </PlanItemDetail>
      </PlanItemContent>
    </PlanItem>
  </PlanContent>
  <PlanProgress completed={1} total={3} />
</Plan>
```

## Title

`PlanHeader` is the trigger for the whole plan. It supports two title patterns:

### Using props

Pass the `title` prop directly to `PlanHeader`.

```tsx showLineNumbers
<PlanHeader title="Add email validation" />
```

> This approach does not require the `PlanTitle` component.

### Using components

Use `PlanTitle` as a child for more control.

```tsx showLineNumbers
<PlanHeader>
  <PlanTitle>Add email validation</PlanTitle>
</PlanHeader>
```

## API Reference

### Plan

Root collapsible. Forwards [Collapsible](/docs/components/collapsible) props.

| Prop | Type | Default |
| --- | --- | --- |
| `defaultOpen` | `boolean` | `true` |
| `className` | `string` | `-` |

### PlanHeader

Clickable header that toggles the plan. Pass `title` to render `PlanTitle`.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | `-` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanTitle

Title text for the plan. Rendered automatically when `title` is set on
`PlanHeader`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanContent

Holds nested plan items.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanItem

A unit of work with a status. Set `collapsible` to reveal details.

| Prop | Type | Default |
| --- | --- | --- |
| `status` | `"pending" \| "in-progress" \| "completed" \| "error"` | `"pending"` |
| `collapsible` | `boolean` | `false` |
| `className` | `string` | `-` |

### PlanItemTrigger

Displays status and title. Shows a chevron when the item is `collapsible`.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | **required** |
| `status` | `"pending" \| "in-progress" \| "completed" \| "error"` | inherits `PlanItem` status |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanItemContent

Contains the details revealed when a collapsible item is open.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanItemDetail

A supporting line for progress, context, files, or custom content.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanItemDetailFile

A compact file reference for use inside a plan item detail.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "secondary" \| "outline" \| "success" \| "info" \| "warning" \| "destructive"` | `"outline"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PlanProgress

Full-width footer with completed count and a progress track. Stays visible when
the plan is collapsed.

| Prop | Type | Default |
| --- | --- | --- |
| `completed` | `number` | **required** |
| `total` | `number` | **required** |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
