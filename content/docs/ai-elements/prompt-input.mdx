## Usage

```tsx
import {
  PromptInput,
  PromptInputBottom,
  PromptInputFooter,
  PromptInputSubmit,
  PromptInputTextarea,
  PromptInputTools,
} from "@/components/ui/prompt-input";
```

```tsx
<PromptInput onSubmit={({ text }) => send(text)} onStop={stop}>
  <PromptInputTextarea aria-label="Prompt" />
  <PromptInputFooter>
    <PromptInputTools />
    <PromptInputSubmit />
  </PromptInputFooter>
  <PromptInputBottom>Project context</PromptInputBottom>
</PromptInput>
```

## API Reference

### PromptInput

The textarea sits above a footer toolbar inside the same field. Enter submits, Shift+Enter inserts a new line.

| Prop | Type | Default |
| --- | --- | --- |
| `status` | `"ready" \| "submitted" \| "streaming" \| "error"` | `"ready"` |
| `onSubmit` | `(detail: { text: string; event: FormEvent }) => void` | `-` |
| `onStop` | `() => void` | `-` |
| `className` | `string` | `-` |

### PromptInputHeader

Addon above the textarea. Place attachment chips here.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### PromptInputTextarea

Message field. Submits on Enter unless `status` is `"submitted"` or `"streaming"`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### PromptInputFooter

Addon below the textarea for tools and submit.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### PromptInputBottom

Optional content area below the composer border. Use it for project or environment context.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### PromptInputTools

Container for composer actions.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### PromptInputPopover

Popover for attach and context actions.

| Prop | Type | Default |
| --- | --- | --- |
| `modal` | `boolean` | `false` |
| `className` | `string` | `-` |

### PromptInputPopoverTrigger

Trigger for the popover.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |

### PromptInputPopoverAction

Action row inside `PromptInputPopoverContent`. Closes the popover on select.

| Prop | Type | Default |
| --- | --- | --- |
| `icon` | `ReactNode` | `-` |
| `description` | `ReactNode` | `-` |
| `className` | `string` | `-` |

### PromptInputButton

Tool button.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "link" \| "destructive"` | `"ghost"` |
| `size` | `"xs" \| "sm" \| "icon-xs" \| "icon-sm"` | `"xs"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### PromptInputSubmit

Send control. Uses an up arrow when ready, a spinner for `"submitted"`, and a stop control for `"streaming"`. Disabled while the textarea is empty unless streaming.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "link" \| "destructive"` | `"default"` |
| `size` | `"xs" \| "sm" \| "icon-xs" \| "icon-sm"` | `"icon-sm"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
