## Usage

```tsx
import { Button } from "@/components/ui/button";
import {
  Context,
  ContextContent,
  ContextFooter,
  ContextHeader,
  ContextMeter,
  ContextTitle,
  ContextTrigger,
  ContextTriggerLabel,
} from "@/components/ui/context";
```

```tsx
const segments = [
  { title: "Input", value: 42_000, color: "var(--chart-1)" },
  { title: "Output", value: 18_500, color: "var(--chart-2)" },
  { title: "Reasoning", value: 12_800, color: "var(--chart-3)" },
  { title: "Cache", value: 6200, color: "var(--chart-4)" },
];

<Context maxTokens={128000} usedTokens={79500} costLabel="$0.18">
  <ContextTrigger asChild>
    <Button size="sm" variant="ghost">
      <ContextTriggerLabel />
    </Button>
  </ContextTrigger>
  <ContextContent>
    <ContextHeader title="Context Usage">
      <ContextMeter segments={segments} />
    </ContextHeader>
    <ContextFooter />
  </ContextContent>
</Context>
```

### Custom meter

Omit summary or legend by composing meter parts:

```tsx showLineNumbers
<ContextMeter segments={segments}>
  <ContextMeterBar />
</ContextMeter>
```

## Title

`ContextHeader` supports two title patterns:

### Using props

Pass the `title` prop directly to `ContextHeader`.

```tsx showLineNumbers
<ContextHeader title="Context Usage">
  <ContextMeter />
</ContextHeader>
```

> This approach does not require the `ContextTitle` component.

### Using components

Use `ContextTitle` as a child when you need more control, such as a close
button.

```tsx showLineNumbers
<ContextHeader>
  <ContextTitle showCloseButton>Context Usage</ContextTitle>
  <ContextMeter />
</ContextHeader>
```

## API Reference

### Context

Root [Popover](/docs/components/popover). Provides token usage to child parts.

| Prop | Type | Default |
| --- | --- | --- |
| `usedTokens` | `number` | `required` |
| `maxTokens` | `number` | `required` |
| `costLabel` | `string` | `-` |
| `className` | `string` | `-` |

### useContextValue

Hook for custom parts. Returns `{ usedTokens, maxTokens, usedPercent, costLabel }`.

### ContextTrigger

Opens the popover on click. Use `asChild` with a single `Button`.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `required` |
| `className` | `string` | `-` |

### ContextTriggerLabel

Percent label and usage icon for the trigger. Pass `children` to replace the
default content.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### ContextIcon

Displays context usage as a circular progress icon.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### ContextContent

Holds the usage panel. Forwards [PopoverContent](/docs/components/popover) props.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `-` |

| Prop | Type | Default |
| --- | --- | --- |
| `--space` | `string` | `--spacing(3)` |

### ContextHeader

Layout container for `ContextTitle` and `ContextMeter`.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | `-` |
| `className` | `string` | `-` |

### ContextTitle

Title for the context panel.

| Prop | Type | Default |
| --- | --- | --- |
| `showCloseButton` | `boolean` | `false` |
| `className` | `string` | `-` |

### ContextClose

Dismiss control for the panel. Used by `ContextTitle` when
`showCloseButton` is set.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### ContextMeter

Layout for usage summary, bar, and legend. With no `children`, renders
`ContextMeterSummary`, `ContextMeterBar`, and (when `segments` is set)
`ContextMeterLegend`.

| Prop | Type | Default |
| --- | --- | --- |
| `segments` | `ContextSegment[]` | `-` |
| `className` | `string` | `-` |

`ContextSegment`: `{ title: string; value: number; color: string }`. Prefer
theme chart tokens such as `var(--chart-1)`.

### ContextMeterSummary

Percent and used/max token counts.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### ContextMeterBar

Mono `Progress` bar, or segmented track when `segments` is set on
`ContextMeter`. The segmented fill matches `usedTokens`; segment values
only set relative widths inside that used portion. Remaining track is
`maxTokens - usedTokens`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### ContextMeterLegend

Category rows from `segments`, rendered with `ContextUsageRow`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### ContextBody

Body for token breakdown rows when not using meter `segments`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### ContextFooter

Footer with total cost.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | `Total cost` |
| `className` | `string` | `-` |

### ContextUsageRow

Usage row with a user-defined title and value. Optional `color` shows a
swatch before the title.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | `required` |
| `value` | `number` | `required` |
| `color` | `string` | `-` |
| `className` | `string` | `-` |
