## Usage

```tsx
import {
  CodeBlock,
  CodeBlockActions,
  CodeBlockContent,
  CodeBlockCopy,
  CodeBlockHeader,
} from "@/components/ui/code-block";
```

```tsx
<CodeBlock className="max-h-80" code={source}>
  <CodeBlockHeader title="helpers.ts">
    <CodeBlockActions>
      <CodeBlockCopy />
    </CodeBlockActions>
  </CodeBlockHeader>
  <CodeBlockContent highlightedLines={[2]} showLineNumbers />
</CodeBlock>
```

## Title

`CodeBlockHeader` supports two title patterns:

### Using props

```tsx showLineNumbers
<CodeBlockHeader title="helpers.ts">
  <CodeBlockActions>
    <CodeBlockCopy />
  </CodeBlockActions>
</CodeBlockHeader>
```

### Using components

```tsx showLineNumbers
<CodeBlockHeader>
  <CodeBlockTitle>helpers.ts</CodeBlockTitle>
  <CodeBlockActions>
    <CodeBlockCopy />
  </CodeBlockActions>
</CodeBlockHeader>
```

## API Reference

### CodeBlock

| Prop | Type | Default |
| --- | --- | --- |
| `code` | `string` | `""` |
| `language` | `CodeBlockLanguage` | `"tsx"` |
| `isStreaming` | `boolean` | `false` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### CodeBlockHeader

Header for the title and actions.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | `-` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### CodeBlockTitle

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### CodeBlockFilename

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### CodeBlockActions

Right-aligned actions container.

### CodeBlockCopy

Copies `code` from `CodeBlock`.

| Prop | Type | Default |
| --- | --- | --- |
| `timeout` | `number` | `2000` |
| `className` | `string` | `-` |

### CodeBlockContent

| Prop | Type | Default |
| --- | --- | --- |
| `showLineNumbers` | `boolean` | `false` |
| `highlightedLines` | `number[]` | `[]` |
| `code` | `string` | - |
| `language` | `CodeBlockLanguage` | - |
| `isStreaming` | `boolean` | - |
| `className` | `string` | `-` |

`CodeBlockLanguage` accepts every bundled Shiki language and `"text"`.
