## Usage

```tsx
import {
  MessageScroller,
  MessageScrollerButton,
  MessageScrollerContent,
  MessageScrollerItem,
  MessageScrollerStick,
  MessageScrollerViewport,
} from "@/components/ui/message-scroller";
```

```tsx
<MessageScroller>
  <MessageScrollerViewport>
    <MessageScrollerStick itemCount={messages.length} layoutKey={latestText} />
    <MessageScrollerContent>
      <MessageScrollerItem />
    </MessageScrollerContent>
  </MessageScrollerViewport>
  <MessageScrollerButton />
</MessageScroller>
```

## API Reference

### MessageScroller

Root scroll area for a transcript.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

| Prop | Type | Default |
| --- | --- | --- |
| `--fade-size` | `string` | `1.5rem` |

### MessageScrollerViewport

Scrollable viewport with edge fade masks.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### MessageScrollerContent

Column of messages inside the viewport.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### MessageScrollerItem

A single message row.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### MessageScrollerStick

Pins the viewport to the latest content while the user stays near the bottom. Mount inside `MessageScrollerViewport`.

| Prop | Type | Default |
| --- | --- | --- |
| `itemCount` | `number` | `-` |
| `layoutKey` | `string \| number` | `-` |
| `enabled` | `boolean` | `true` |
| `paused` | `boolean` | `false` |

### MessageScrollerButton

Jump control. When `MessageScrollerStick` is mounted, jump visibility uses a 64px near-bottom threshold instead of Ark’s exact edge.

| Prop | Type | Default |
| --- | --- | --- |
| `direction` | `"start" \| "end"` | `"end"` |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "link" \| "destructive"` | `"secondary"` |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl" \| "icon-xs" \| "icon-sm" \| "icon-md" \| "icon-lg" \| "icon-xl"` | `"icon-sm"` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
