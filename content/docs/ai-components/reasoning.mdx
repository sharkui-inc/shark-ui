## API Reference

### Reasoning

Root collapsible. When uncontrolled, opens when `isStreaming` becomes true (including after mount) and stays open when streaming ends. Controlled `open` is respected. `duration` and `isStreaming` are available to `ReasoningTrigger`.

| Prop | Type | Default |
| --- | --- | --- |
| `duration` | `number` | `-` |
| `isStreaming` | `boolean` | `false` |
| `translations` | `Partial<ReasoningTranslations>` | - |
| `className` | `string` | `-` |

### ReasoningTrigger

Toggles the reasoning. Its default label comes from the root `translations`: `thought`, `thinking`, or `thoughtForDuration`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### ReasoningContent

Holds the reasoning text.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
