description: A guide to installing Shark UI in a TanStack Start project.
---

## New project

<Steps>

<Step>Install the Shark theme, every component, and visual utilities in a new TanStack Start project:</Step>

```bash
npx shadcn@latest init @shark/starter -t start
```

For a monorepo, add `--monorepo`.

</Steps>

## Existing project

<Steps>

<Step>If needed, create a TanStack Start app with the TanStack CLI.</Step>

```bash
npx @tanstack/cli@latest create
```

Choose TanStack Start, React, and the recommended defaults. They configure Tailwind CSS and `@/*`. Do not select the shadcn add-on.

<Step>Add the Shark foundation: theme tokens, utils, and animations. No components are added.</Step>

```bash
npx shadcn@latest init @shark/style
```

<Step>Add components. Install the full catalog without changing the theme:</Step>

```bash
npx shadcn@latest add @shark/ui
```

Or install individual components from the [component docs](/docs/components). 

</Steps>
