---
title: Laravel
description: A guide to installing Shark UI in a Laravel project.
---

## New project

<Steps>

<Step>Create a Laravel project, choose the React starter kit, then enter the project directory.</Step>

```bash
laravel new my-app
cd my-app
```

<Step>Add the Shark theme, every component, and visual utilities.</Step>

```bash
npx shadcn@latest init @shark/starter -t laravel
```

</Steps>

## Existing project

<Steps>

<Step>Use the Laravel React starter kit with Tailwind CSS v4.</Step>

<Step>Add the Shark foundation: theme tokens, utils, and animations. No components are added.</Step>

```bash
npx shadcn@latest init @shark/style
```

Run the command from the Laravel application root. Review any overwrite prompt before confirming.

<Step>Add components. Install the full catalog without changing the theme:</Step>

```bash
npx shadcn@latest add @shark/ui
```

Or install individual components from the [component docs](/docs/components). 

</Steps>
