title: Astro
description: A guide to installing Shark UI in an Astro project.
---

## New project

<Steps>

<Step>Install the Shark theme, every component, and visual utilities in a new Astro project:</Step>

```bash
npx shadcn@latest init @shark/starter -t astro
```

For a monorepo, add `--monorepo`.

</Steps>

## Existing project

<Steps>

<Step>If needed, create an Astro app with the Tailwind CSS template and React integration.</Step>

```bash
npm create astro@latest my-app -- --template with-tailwindcss --install --add react --git
```

Keep the generated layout, or import the global stylesheet in pages that render Shark components.

<Step>Configure `@/*` to resolve to `src/*` if needed.</Step>

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

<Step>Add the Shark foundation: theme tokens, utils, and animations. No components are added.</Step>

```bash
npx shadcn@latest init @shark/style
```

<Step>Add components. Install the full catalog without changing the theme:</Step>

```bash
npx shadcn@latest add @shark/ui
```

Or install individual components from the [component docs](/docs/components). 

</Steps>
