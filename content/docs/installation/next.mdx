---

## New project

<Steps>

<Step>Install the Shark theme, every component, and visual utilities in a new Next.js project:</Step>

```bash
npx shadcn@latest init @shark/starter -t next
```

For a monorepo, add `--monorepo`.

<Step>All components are installed in `@/components/ui` and ready to import.</Step>

```tsx title="app/page.tsx" showLineNumbers
import { Button } from "@/components/ui/button";

export default function Home() {
  return <Button>Click me</Button>;
}
```

</Steps>

## Existing project

<Steps>

<Step>If needed, create the app with the recommended `create-next-app` defaults. It configures Tailwind CSS, the App Router, and the `@/*` alias.</Step>

```bash
npx create-next-app@latest my-app
```

<Step>For an older or custom app, install Tailwind CSS and configure the `@/*` alias before continuing.</Step>

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```

When using `src/`, change the alias target to `./src/*`.

<Step>Add the Shark foundation: theme tokens, utils, and animations. No components are added.</Step>

```bash
npx shadcn@latest init @shark/style
```

<Step>Add components. Install the full catalog without changing the theme:</Step>

```bash
npx shadcn@latest add @shark/ui
```

Or install individual components from the [component docs](/docs/components). 

</Steps>
