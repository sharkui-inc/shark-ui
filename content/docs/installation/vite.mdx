description: A guide to installing Shark UI in a Vite project.
---

## New project

<Steps>

<Step>Install the Shark theme, every component, and visual utilities in a new Vite project:</Step>

```bash
npx shadcn@latest init @shark/starter -t vite
```

For a monorepo, add `--monorepo`.

</Steps>

## Existing project

<Steps>

<Step>If needed, create a Vite app with the React and TypeScript template.</Step>

```bash
npm create vite@latest my-app
```

<Step>Add Tailwind CSS v4 if needed.</Step>

```bash
npm install tailwindcss @tailwindcss/vite
```

```css title="src/index.css"
@import "tailwindcss";
```

<Step>Configure `@/*` to resolve to `src/*`.</Step>

```json title="tsconfig.app.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

Add the same entries to `tsconfig.json`.

```bash
npm install -D @types/node
```

```ts title="vite.config.ts"
import path from "path";
import tailwindcss from "@tailwindcss/vite";
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      "@": path.resolve(__dirname, "./src"),
    },
  },
});
```

<Step>Add the Shark foundation: theme tokens, utils, and animations. No components are added.</Step>

```bash
npx shadcn@latest init @shark/style
```

<Step>Add components. Install the full catalog without changing the theme:</Step>

```bash
npx shadcn@latest add @shark/ui
```

Or install individual components from the [component docs](/docs/components). 

</Steps>
