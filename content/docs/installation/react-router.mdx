title: React Router
description: A guide to installing Shark UI in a React Router project.
---

## New project

<Steps>

<Step>Install the Shark theme, every component, and visual utilities in a new React Router project:</Step>

```bash
npx shadcn@latest init @shark/starter -t react-router
```

For a monorepo, add `--monorepo`.

</Steps>

## Existing project

<Steps>

<Step>If needed, create a React Router app first.</Step>

```bash
npx create-react-router@latest my-app
```

`create-react-router` configures Tailwind CSS and `~/*`. Shark components use `@/*`, so map it to `app/*`.

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./app/*"]
    }
  }
}
```

Configure the same alias in Vite. Custom projects also need Tailwind CSS.

<Step>Add the Shark foundation: theme tokens, utils, and animations. No components are added.</Step>

```bash
npx shadcn@latest init @shark/style
```

<Step>Add components. Install the full catalog without changing the theme:</Step>

```bash
npx shadcn@latest add @shark/ui
```

Or install individual components from the [component docs](/docs/components). 

</Steps>
