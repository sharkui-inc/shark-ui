## Approach

Formisch holds state. Valibot validates. `Field` wraps each control.

- `useForm` for state
- `Form` for submit
- Import Formisch’s `Field` as `FormischField` for each control
- Shark `Field` for label, description, and error
- `schema` with your Valibot schema

## Anatomy

Each control sits in `FormischField`, then `Field`.

```tsx showLineNumbers {5-12}
<Form of={form} onSubmit={onSubmit}>
  <FieldGroup>
    <FormischField of={form} path={["title"]}>
      {(field) => (
        <Field invalid={Boolean(field.errors?.length)}>
          <FieldLabel>Bug Title</FieldLabel>
          <Input {...field.props} value={field.input} />
           <FieldDescription>
            Provide a concise title for your bug report.
          </FieldDescription>
          <FieldError>{field.errors?.[0]}</FieldError>
        </Field>
      )}
    </FormischField>
  </FieldGroup>
  <Button type="submit">Submit</Button>
</Form>
```

### Setup

- Create the form with `useForm` from Formisch and pass your schema to `schema`.
- Wrap fields in `Form` and handle submit on `onSubmit`.

```tsx showLineNumbers title="form.tsx" {9-15,18-20}
import { Form, Field as FormischField, useForm } from "@formisch/react";
import * as v from "valibot";

const formSchema = v.object({
  // ...
});

export const BugReportForm = () => {
  const form = useForm({
    schema: formSchema,
    initialInput: {
      title: "",
      description: "",
    },
  });

  return (
    <Form of={form} onSubmit={(output) => console.log(output)}>
      {/* Build the form here */}
    </Form>
  );
};
```

## Validation

### Client-side

Pass the Valibot schema to `schema` on `useForm`.

```tsx showLineNumbers title="example-form.tsx" {4-7,11}
import { useForm } from "@formisch/react"
import * as v from "valibot"

const formSchema = v.object({
  title: v.string(),
  description: v.optional(v.string()),
})

export const ExampleForm = () => {
  const form = useForm({
    schema: formSchema,
    initialInput: {
      title: "",
      description: "",
    },
  })
}
```

### Modes

Configure when validation runs via the `validate` and `revalidate` options:

```tsx showLineNumbers title="form.tsx" {3-4}
const form = useForm({
  schema: formSchema,
  validate: "submit",
  revalidate: "input",
})
```

| Option | Role |
| --- | --- |
| `"initial"` | Validation triggers on initial render. |
| `"touch"` | Validation triggers on field touch. |
| `"input"` | Validation triggers on field input. |
| `"change"` | Validation triggers on field change. |
| `"blur"` | Validation triggers on field blur. |
| `"submit"` | Validation triggers on form submit. |

## Displaying Errors

Set `invalid` on `Field`. Skip it on `Input`, `Checkbox`, and the other controls.

```tsx showLineNumbers title="form.tsx" {3,6}
<FormischField of={form} path={["email"]}>
  {(field) => (
    <Field invalid={Boolean(field.errors?.length)}>
      <FieldLabel>Email</FieldLabel>
      <Input {...field.props} type="email" value={field.input} />
      <FieldError>{field.errors?.[0]}</FieldError>
    </Field>
  )}
</FormischField>
```

## Array Fields

`FieldArray` renders the list. `insert` and `remove` change items.

<ComponentPreview componentName="form/formisch" fileName="example-array-emails" showBorders={false} autoHeight />

### Array Field Structure

Pass the form to `FieldArray` via `of`.

```tsx showLineNumbers title="form.tsx" {9-15}
import { FieldArray, Field as FormischField, useForm } from "@formisch/react";

export const ExampleForm = () => {
  const form = useForm({
    // ... form config
  });

  return (
    <FieldArray of={form} path={["emails"]}>
      {(arrayField) => (
        arrayField.items.map((itemId, index) => (
          // Nested field for each array item
        ))
      )}
    </FieldArray>
  );
}
```

### Nested Fields

Render each item from `arrayField.items` with the matching path.

```tsx showLineNumbers title="form.tsx"
{
  arrayField.items.map((itemId, index) => (
    <FormischField 
      key={itemId} 
      of={form} 
      path={["emails", index, "contact", "address"]}
    >
      {(field) => (
        <Field invalid={Boolean(field.errors?.length)} orientation="horizontal">
          <FieldContent>
            <InputGroup>
              <InputGroupInput
                {...field.props}
                autoComplete="email"
                onChange={(e) => field.onChange(e.target.value)}
                placeholder="name@example.com"
                type="email"
                value={field.input}
              />
              {arrayField.items.length > 1 && (
                <InputGroupAddon align="inline-end">
                  <InputGroupButton
                    aria-label={`Remove email ${String(index + 1)}`}
                    onClick={() =>
                      remove(form, { path: ["emails"], at: index })
                    }
                    size="icon-xs"
                    variant="ghost"
                  >
                    <XIcon aria-hidden className="size-4" />
                  </InputGroupButton>
                </InputGroupAddon>
              )}
            </InputGroup>
            <FieldError>{field.errors?.[0]}</FieldError>
          </FieldContent>
        </Field>
      )}
    </FormischField>
  ))
}
```

### Adding items

- Call `insert` to add an item.
- Pass `initialInput` that matches the nested element.

```tsx showLineNumbers title="form.tsx"
import { insert } from "@formisch/react";

<Button
  variant="outline"
  size="sm"
  onClick={() =>
    insert(form, {
      path: ["emails"],
      initialInput: { contact: { address: "" } },
    })
  }
  disabled={arrayField.items.length >= 5}
>
  Add Email Address
</Button>
```

### Removing items

Use `remove` with the array path and index.

```tsx showLineNumbers title="form.tsx"
import { remove } from "@formisch/react";

{

        variant="ghost"
        size="icon-xs"

```

### Array validation

Validate the list with `v.array()`, then `minLength` / `maxLength`.

```tsx showLineNumbers title="form.tsx"
import * as v from "valibot";

const formSchema = v.object({
  emails: v.pipe(
    v.array(
      v.object({
        contact: v.object({
          address: v.pipe(
            v.string(),
            v.nonEmpty("Enter an email address."),
            v.email("Enter a valid email address.")
          ),
        }),
      })
    ),
    v.minLength(1, "Add at least one email address."),
    v.maxLength(5, "You can add up to 5 email addresses.")
  ),
});
```
