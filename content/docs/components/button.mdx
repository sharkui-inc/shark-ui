## Usage

```tsx
import { Button } from "@/components/ui/button";
```

```tsx
<Button>Button</Button>
```

## Icons

Mark inline icons with `data-icon` so they follow the reading direction.

```tsx
import { ArrowRightIcon, PlusIcon } from "lucide-react";
import { Button } from "@/components/ui/button";

<Button>
  <PlusIcon data-icon="inline-start" />
  Add
</Button>

<Button variant="outline">
  Continue
  <ArrowRightIcon data-icon="inline-end" className="rtl:rotate-180" />
</Button>
```

## Link

There are two ways to render another element with button styling: 

- Pass `asChild` on `Button`;
- Apply `buttonVariants` as `className` on the element itself;

## API Reference

| Prop | Type | Default |
| --- | --- | --- | 
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "link" \| "destructive"` | `"default"` | 
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl" \| "icon-xs" \| "icon-sm" \| "icon-md" \| "icon-lg" \| "icon-xl"` | `"md"` |
| `pill` | `boolean` | `false` |
| `clickEffect` | `boolean` | `true` | 
| `isLoading` | `boolean` | `false` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
### Button

Public Button component. It forwards the underlying primitive props.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |
