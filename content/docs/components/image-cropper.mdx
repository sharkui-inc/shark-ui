## Usage

```tsx

  ImageCropper,
  ImageCropperImage,
  ImageCropperSelection,
} from "@/components/ui/image-cropper";
```

```tsx

  <ImageCropperImage alt="Crop me" src="/image.jpg" />
  <ImageCropperSelection />
</ImageCropper>
```

## API Reference

### ImageCropper

Root wrapper. Manages crop state and handles.

| Prop | Type | Default |
| --- | --- | --- |
| `aspectRatio` | `number` | - |
| `cropShape` | `"circle" \| "rectangle"` | `"rectangle"` |
| `fixedCropArea` | `boolean` | `false` |
| `initialCrop` | `{ x: number; y: number; width: number; height: number }` | - |
| `maxHeight` | `number` | `Infinity` |
| `maxWidth` | `number` | `Infinity` |
| `maxZoom` | `number` | `5` |
| `minHeight` | `number` | `40` |
| `minWidth` | `number` | `40` |
| `minZoom` | `number` | `1` |
| `onCropChange` | `(details: CropChangeDetails) => void` | - |
| `onZoomChange` | `(details: ZoomChangeDetails) => void` | - |
| `rotation` | `number` | - |
| `zoom` | `number` | - |
| `className` | `string` | - |

| Prop | Type | Default |
| --- | --- | --- |
| `--cropper-accent` | `string` | `var(--color-white)` |
| `--cropper-handler-size` | `string` | `--spacing(2)` |
| `--cropper-handler-width` | `string` | `--spacing(1)` |

### ImageCropperImage

Image to crop. Pass `src` and alt.

| Prop | Type | Default |
| --- | --- | --- |
| `alt` | `string` | - |
| `src` | `string` | - |
| `className` | `string` | - |

### ImageCropperSelection

Crop selection overlay with resize handles and optional grid.

| Prop | Type | Default |
| --- | --- | --- |
| `axis` | `"horizontal" \| "vertical" \| "both"` | `"both"` |
| `className` | `string` | - |

### ImageCropperRootProvider

Provides a ImageCropper API created with `useImageCropper` to descendant components.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `UseImageCropperReturn` | **required** |

### ImageCropperContext

Render-prop access to the surrounding component API.

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `(api: unknown) => React.ReactNode` | **required** |

### ImageCropperHandle

Public ImageCropperHandle component. It forwards the underlying primitive props.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | - |

### ImageCropperGrid

Public ImageCropperGrid component. It forwards the underlying primitive props.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | - |

---

For a complete list of props, see the [Ark UI documentation](https://ark-ui.com/docs/components/image-cropper#api-reference).
