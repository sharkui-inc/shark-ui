## Usage

```tsx
import { 
  HoverCard, 
  HoverCardContent,
  HoverCardTrigger,
} from "@/components/ui/hover-card";
```

```tsx
<HoverCard>
  <HoverCardTrigger />
  <HoverCardContent>
    {/* Content */}
  </HoverCardContent>
</HoverCard>
```
## Trigger Delays

The `openDelay` and `closeDelay` props control the delay before the hover card opens and closes respectively.

Default values are `600ms` for `openDelay` and `300ms` for `closeDelay`.

## API Reference

### HoverCard

Root component. Manages hover state and content visibility.

| Prop | Type | Default |
| --- | --- | --- |
| `closeDelay` | `number` | `300` |
| `defaultOpen` | `boolean` | - |
| `disabled` | `boolean` | - |
| `immediate` | `boolean` | - |
| `onOpenChange` | `(details: OpenChangeDetails) => void` | - |
| `onTriggerValueChange` | `(details: TriggerValueChangeDetails) => void` | - |
| `open` | `boolean` | - |
| `openDelay` | `number` | `600` |
| `positioning` | `PositioningOptions` | `{ placement: "top" }` |
| `className` | `string` | `-` |

### HoverCardTrigger

Shows the hover card on hover or focus.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | - |
| `value` | `string` | - |

### HoverCardContent

Content shown in a popover when hover card is open.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | - |
| `showArrow` | `boolean` | `true` |

### HoverCardArrow

Optional arrow pointing toward the trigger.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | - |

| Prop | Type | Default |
| --- | --- | --- |
| `--arrow-background` | `string` | `var(--popover)` |
| `--arrow-size` | `string` | `calc(1.5 * var(--spacing))` |

### HoverCardRootProvider

Provides a HoverCard API created with `useHoverCard` to descendant components.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `UseHoverCardReturn` | **required** |

---

For a complete list of props, see the [Ark UI documentation](https://ark-ui.com/docs/components/hover-card#api-reference).
