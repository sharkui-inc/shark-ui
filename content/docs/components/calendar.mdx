## Usage

```tsx
import {
  Calendar,
  CalendarNextTrigger,
  CalendarPrevTrigger,
  CalendarTable,
  CalendarTableDays,
  CalendarViewControl,
  CalendarViewDate,
  CalendarWeekDays,
} from "@/components/ui/calendar";
```

```tsx showLineNumbers
<Calendar>
  <CalendarViewControl>
    <CalendarPrevTrigger />
    <CalendarViewDate />
    <CalendarNextTrigger />
  </CalendarViewControl>
  <CalendarTable>
    <CalendarWeekDays />
    <CalendarTableDays />
  </CalendarTable>
</Calendar>
```

### Week numbers

Set `showWeekNumbers` to render a week-number column. `CalendarWeekDays` and `CalendarTableDays` include it automatically.

<ComponentPreview componentName="calendar" fileName="example-week-numbers" />

### Max selected dates

In `selectionMode="multiple"`, `maxSelectedDates` caps how many days can be selected.

<ComponentPreview componentName="calendar" fileName="example-max-selected" />

### Custom Cell Size

Use `[--cell-size:--spacing("value")]` to set the size of the calendar cells.

Default value is `--spacing(9)`.

<ComponentPreview componentName="calendar" fileName="example-custom-cell-size" />

> You can use breakpoint utilities to change the cell size at different screen sizes.

```css
  md:[--cell-size:--spacing(10)] lg:[--cell-size:--spacing(12)]
```

## API Reference

### Calendar

Root component. Manages date view, selection, and navigation.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `DateValue[]` | `-` |
| `defaultValue` | `DateValue[]` | `-` |
| `onValueChange` | `(details: ValueChangeDetails) => void` | `-` |
| `selectionMode` | `"single" \| "range" \| "multiple"` | `"single"` |
| `createCalendar` | `(identifier: string) => Calendar` | `-` |
| `showWeekNumbers` | `boolean` | `-` |
| `maxSelectedDates` | `number` | `-` |
| `min` | `DateValue` | `-` |
| `max` | `DateValue` | `-` |
| `isDateUnavailable` | `(date: DateValue) => boolean` | `-` |
| `fixedWeeks` | `boolean` | `false` |
| `outsideDaySelectable` | `boolean` | `false` |
| `numOfMonths` | `number` | `1` |
| `required` | `boolean` | `-` |
| `invalid` | `boolean` | `-` |
| `locale` | `string` | `-` |
| `className` | `string` | `-` |

| Prop | Type | Default |
