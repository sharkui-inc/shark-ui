## Usage

```tsx
import { 
  Tour, 
  TourTrigger, 
  TourContent, 
  TourHeader,
  TourProgressText,
  TourTitle,
  TourDescription,
  TourFooter,
  TourNextStep,
  TourPreviousStep,
  useTour,
} from "@/components/ui/tour";
```

```tsx
const tour = useTour({ steps });

<Tour tour={tour}>
  <TourTrigger />
  <TourContent>
    <TourHeader>
      <TourProgressText />
      <TourTitle />
      <TourDescription />
    </TourHeader>
    <TourFooter>
      <TourPreviousStep />
      <TourNextStep />
    </TourFooter>
  </TourContent>
</Tour>
```

## Title & Description

`TourHeader` supports two usage patterns:

### Using props

Pass `title` and `description` props directly to `TourHeader`.

```tsx showLineNumbers
<TourHeader title="Tour Title" description="Tour description">
  <TourProgressText />
</TourHeader>
```

> This approach does not require `TourTitle` or `TourDescription` components.

### Using components

Use `TourTitle` and `TourDescription` as children for more control.

```tsx showLineNumbers
<TourHeader>
  <TourProgressText />
  <TourTitle>Tour Title</TourTitle>
  <TourDescription>Tour description</TourDescription>
</TourHeader>
```

## API Reference

### useTour

Creates the tour machine. Pass the return value to `Tour` as `tour`.

| Prop | Type | Default |
| --- | --- | --- |
| `steps` | `TourStepType[]` | - |
| `keyboardNavigation` | `boolean` | `true` |
| `closeOnInteractOutside` | `boolean` | `true` |
| `closeOnEscape` | `boolean` | `true` |
| `onStepChange` | `(details: TourStepChangeDetails) => void` | - |
| `onStatusChange` | `(details: TourStatusChangeDetails) => void` | - |

### Tour

Root provider for a tour created with `useTour`.

| Prop | Type | Default |
| --- | --- | --- |
| `tour` | `UseTourReturn` | **required** |
| `lazyMount` | `boolean` | `true` |
| `unmountOnExit` | `boolean` | `true` |
| `hideMode` | `"display-none" \| "activity"` | `"display-none"` |

### TourTrigger

Starts the tour on click. Use `asChild` for a custom trigger.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | - |
| `className` | `string` | - |

### TourContent

Tour panel, including the overlay, spotlight, arrow, and close button.

| Prop | Type | Default |
| --- | --- | --- |
| `bottomStickOnMobile` | `boolean` | `true` |
| `showCloseButton` | `boolean` | `true` |
| `showArrow` | `boolean` | `true` |
| `className` | `string` | - |

| Prop | Type | Default |
| --- | --- | --- |
| `--space` | `string` | `--spacing(4)` |

### TourHeader

Header area. Accepts `title` and `description` or children.

| Prop | Type | Default |
| --- | --- | --- |
| `title` | `string` | - |
| `description` | `string` | - |
| `className` | `string` | - |

### TourTitle

Accessible title. Falls back to the current step title.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | - |
| `className` | `string` | - |

### TourDescription

Accessible description. Falls back to the current step description.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | - |
| `className` | `string` | - |

### TourProgressText

Current step and total.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | - |
| `className` | `string` | - |

### TourFooter

Footer for `TourPreviousStep` and `TourNextStep`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

### TourActions

Renders the actions of the current step.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

### TourPreviousStep

Renders the step's `"prev"` action.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

### TourNextStep

Renders the `"next"` action, or `"dismiss"` when the step has no `"next"`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

### TourClose

Closes the tour on click. Use `asChild` for a custom close element.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | - |
| `className` | `string` | - |

### TourActionTrigger

Runs one step action.

| Prop | Type | Default |
| --- | --- | --- |
| `action` | `StepAction` | **required** |
| `asChild` | `boolean` | - |
| `className` | `string` | - |

### TourOverlay

Dimmed backdrop. Rendered by `TourContent`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

### TourPositioner

Positions the panel. Rendered by `TourContent`.

| Prop | Type | Default |
| --- | --- | --- |
| `bottomStickOnMobile` | `boolean` | `true` |
| `className` | `string` | - |

### TourBody

Scrollable body content.

| Prop | Type | Default |
| --- | --- | --- |
| `scrollFade` | `boolean` | `true` |
| `className` | `string` | - |

### TourSpotlight

Highlight around the step target. Rendered by `TourContent`.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

### TourArrow

Arrow for tooltip steps.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

| Prop | Type | Default |
| --- | --- | --- |
| `--arrow-background` | `string` | `var(--popover)` |
| `--arrow-size` | `string` | `calc(1.5 * var(--spacing))` |

### useTourContext

Tour API for components inside `Tour`.

| Property | Type |
| --- | --- |
| `open` | `boolean` |
| `step` | `TourStepType \| null` |
| `stepIndex` | `number` |
| `totalSteps` | `number` |
| `start` | `(id?: string) => void` |
| `next` | `() => void` |
| `prev` | `() => void` |
| `getProgressText` | `() => string` |
| `getProgressPercent` | `() => number` |
