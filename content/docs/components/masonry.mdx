## Usage


```tsx

  <MasonryItem>{/* Content */}</MasonryItem>
  <MasonryItem>{/* Content */}</MasonryItem>
  <MasonryItem>{/* Content */}</MasonryItem>
</Masonry>
```

## Reflow

Reflow is the process of recalculating the layout of the items in the masonry.

### Stable

Keeps items in their column when height changes.

<ComponentPreview componentName="masonry" fileName="example-reflow-stable" autoHeight />

### Balanced

Rebalances columns on each layout pass.

## API Reference

### Masonry

Root container.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | - |
| `reflow` | `"stable" \| "balanced"` | `"stable"` |

| Prop | Type | Default |
| --- | --- | --- |
| `--gap` | `string` | `--spacing(4)` |

### MasonryItem

Item wrapper.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | - |
