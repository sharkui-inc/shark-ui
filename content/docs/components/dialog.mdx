## Anatomy

```text
Dialog
├── DialogTrigger
└── DialogContent
    ├── DialogHeader
    │   ├── DialogTitle
    │   └── DialogDescription
    ├── DialogBody
    └── DialogFooter
        └── DialogClose
```

## Usage

```tsx
import { 
  Dialog, 
  DialogTrigger, 
  DialogContent, 
  DialogHeader,
  DialogTitle, 
  DialogDescription, 
  DialogBody,
  DialogFooter,
  DialogClose,
} from "@/components/ui/dialog";
```

```tsx
<Dialog>
  <DialogTrigger />
  <DialogContent>
    <DialogHeader>
      <DialogTitle />
      <DialogDescription />
    </DialogHeader>
    <DialogBody>
      {/** your content here */}
    </DialogBody>
    <DialogFooter>
      <DialogClose />
    </DialogFooter>
  </DialogContent>
</Dialog>
```

## Title & Description

`DialogHeader` supports two usage patterns:

### Using props

Pass `title` and `description` props directly to `DialogHeader`. 

```tsx showLineNumbers
<DialogHeader title="Dialog Title" description="Dialog description" />
```

> This approach does not require `DialogTitle` or `DialogDescription` components.

### Using components

Use `DialogTitle` and `DialogDescription` as children for more control.

```tsx showLineNumbers
<DialogHeader>
  <DialogTitle>Dialog Title</DialogTitle>
  <DialogDescription>Dialog description</DialogDescription>
</DialogHeader>
```

## API Reference

### Dialog

Root context provider. Controls open state and modal behavior.

| Prop | Type | Default |
|------|------|---------|
| `open` | `boolean` | `-` |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `({ open }: OpenChangeDetails) => void` | `-` |
| `onTriggerValueChange` | `(details: TriggerValueChangeDetails) => void` | `-` |
| `modal` | `boolean` | `true` |
| `closeOnEscape` | `boolean` | `true` |
| `closeOnInteractOutside` | `boolean` | `true` |
| `initialFocusEl` | `() => MaybeElement` | `-` |
| `finalFocusEl` | `() => MaybeElement` | `-` |
| `lazyMount` | `boolean` | `true` |
| `unmountOnExit` | `boolean` | `true` |
| `hideMode` | `"display-none" \| "activity"` | `"display-none"` |
| `onEnterComplete` | `() => void` | `-` |
| `onEscapeKeyDown` | `(event: KeyboardEvent) => void` | `-` |
| `onInteractOutside` | `(event: InteractOutsideEvent) => void` | `-` |
| `className` | `string` | `-` |

### DialogTrigger

Opens the dialog on click. Use `asChild` for custom trigger elements. 

| Prop | Type | Default |
|------|------|---------|
| `asChild` | `boolean` | `false` |
| `value` | `string` | `-` |
| `className` | `string` | `-` |

### DialogContent

Holds the dialog panel. Supports size variants from sm to fullscreen. 

| Prop | Type | Default |
|------|------|---------|
| `size` | `"sm" \| "md" \| "lg" \| "xl" \| "2xl" \| "3xl" \| "4xl" \| "5xl" \| "6xl" \| "fullscreen"` | `"md"` |
| `showCloseButton` | `boolean` | `true` |
| `bottomStickOnMobile` | `boolean` | `true` |
| `className` | `string` | `-` |

| Prop | Type | Default |
| --- | --- | --- |
| `--space` | `string` | `--spacing(6)` |

### DialogHeader

Header area for title and description. Accepts props or children.

| Prop | Type | Default |
|------|------|---------|
| `title` | `string` | `-` |
| `description` | `string` | `-` |
| `className` | `string` | `-` |

### DialogBody

Scrollable body content.

| Prop | Type | Default |
|------|------|---------|
| `scrollFade` | `boolean` | `true` |
| `className` | `string` | `-` |

### DialogFooter

Footer area for action buttons.

Put the primary action **first in the DOM**, then Cancel. The footer uses `flex-col` / `sm:flex-row-reverse` so the visual order stays Cancel on the left and Confirm on the right (Confirm on top on mobile). That way Tab and initial focus hit Confirm when there is no earlier field.

| Prop | Type | Default |
|------|------|---------|
| `className` | `string` | `-` |

### DialogTitle

Accessible title for the dialog. Announced to screen readers.

| Prop | Type | Default |
|------|------|---------|
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |

### DialogDescription

Accessible description for the dialog. Announced to screen readers. 

| Prop | Type | Default |
|------|------|---------|
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |

### DialogClose

Closes the dialog on click. Use `asChild` for custom close elements. 

| Prop | Type | Default |
|------|------|---------|
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |

### DialogOverlay

Dimmed overlay behind the dialog panel.

| Prop | Type | Default |
|------|------|---------|
| `className` | `string` | `-` |

### DialogRootProvider

Provides a Dialog API created with `useDialog` to descendant components.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `UseDialogReturn` | **required** |
| `modal` | `boolean` | `true` |

`modal` gates `DialogOverlay` the same way as on `Dialog`. Pass the same value you used in `useDialog` when it is not the default.

### DialogPositioner

Public DialogPositioner component. It forwards the underlying primitive props.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | - |
