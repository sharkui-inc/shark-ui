## Usage

```tsx
import {
  Pagination,
  PaginationFirst,
  PaginationItems,
  PaginationLast,
  PaginationNext,
  PaginationPrevious,
} from "@/components/ui/pagination";
```

```tsx
<Pagination>
  <PaginationFirst />
  <PaginationPrevious />
  <PaginationItems />
  <PaginationNext />
  <PaginationLast />
</Pagination>
```

## API Reference

### Pagination

| Prop | Type | Default |
| --- | --- | --- |
| `count` | `number` | `-` |
| `page` | `number` | `-` |
| `defaultPage` | `number` | `1` |
| `pageSize` | `number` | `-` |
| `defaultPageSize` | `number` | `10` |
| `siblingCount` | `number` | `1` |
| `boundaryCount` | `number` | `1` |
| `type` | `"button" \| "link"` | `"button"` |
| `getPageUrl` | `(details: PageUrlDetails) => string` | `-` |
| `onPageChange` | `(details: PageChangeDetails) => void` | `-` |
| `onPageSizeChange` | `(details: PageSizeChangeDetails) => void` | `-` |

### PaginationRootProvider

Provides a Pagination API created with `usePagination` to descendant components.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `UsePaginationReturn` | `required` |
| `type` | `"button" \| "link"` | `"button"` |

Pass the same `type` you used in `usePagination` so link mode renders `<a>` items.
