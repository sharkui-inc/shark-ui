## API Reference

### SignaturePad

Root component. Canvas for drawing signatures. Manages strokes and export.

| Prop | Type | Default |
| --- | --- | --- |
| `disabled` | `boolean` | `false` |
| `required` | `boolean` | `false` |
| `readOnly` | `boolean` | `false` |
| `name` | `string` | `-` |
| `paths` | `string[]` | `-` |
| `defaultPaths` | `string[]` | `-` |
| `onDraw` | `(details: DrawDetails) => void` | `-` |
| `onDrawEnd` | `(details: DrawEndDetails) => void` | `-` |
| `className` | `string` | `-` |

### SignaturePadLabel

Label for the signature drawing surface. Clicking it focuses the control. The control keeps Ark's `signature pad` accessible name.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |

### SignaturePadRootProvider

Provides a SignaturePad API created with `useSignaturePad` to descendant components.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `UseSignaturePadReturn` | `required` |

---

For a complete list of props, see the [Ark UI documentation](https://ark-ui.com/docs/components/signature-pad#api-reference).
