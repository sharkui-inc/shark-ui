## API Reference

### IconTile

A single surface that centers an icon, initials, or short text. 

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "outline" \| "primary"` | `"default"` |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` |
| `fill` | `boolean` | `false` |
| `asChild` | `boolean` | `false` |
| `className` | `string` | - |
