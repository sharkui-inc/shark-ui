## Usage

```tsx
import {
  Menu,
  MenuCheckboxItem,
  MenuContent,
  MenuGroup,
  MenuItem,
  MenuQuickItem,
  MenuRadioGroup,
  MenuRadioItem,
  MenuSeparator,
  MenuShortcut,
  MenuSub,
  MenuSubContent,
  MenuSubTrigger,
  MenuTrigger,
} from "@/components/ui/menu";
```

```tsx
<Menu>
  <MenuTrigger />
  <MenuContent>
    <MenuItemGroup>
      <MenuItemGroupLabel />
      <MenuItem />
      <MenuSub>
        <MenuSubTrigger />
        <MenuSubContent>
          <MenuItem />
        </MenuSubContent>
      </MenuSub>
      <MenuSeparator />
      <MenuItemGroup>
        <MenuRadioItem />
      </MenuItemGroup>
      <MenuSeparator />
      <MenuCheckboxItem />
    </MenuItemGroup>
  </MenuContent>
</Menu>
```

## API Reference

### Menu

Root element of the menu component.

| Prop | Type | Default |
| --- | --- | --- |
| `positioning` | `PositioningOptions` | - |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | - |
| `onOpenChange` | `(details: OpenChangeDetails) => void` | - |
| `onSelect` | `(details: SelectionDetails) => void` | - |
| `closeOnSelect` | `boolean` | `true` |

### MenuTrigger

Opens the menu on click.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | - |

### MenuPositioner

Positions the menu content relative to its trigger.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | - |
| `className` | `string` | - |

### MenuContent

Holds menu options. Displayed in a portal, positioned relative to the trigger.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | - |
| `className` | `string` | - |
| `showArrow` | `boolean` | `false` |

### MenuItem

A single selectable menu option.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | **required** |
| `variant` | `"default" \| "destructive"` | `"default"` |
| `asChild` | `boolean` | - |
| `disabled` | `boolean` | - |
| `closeOnSelect` | `boolean` | - |
| `onSelect` | `VoidFunction` | - |

### MenuCheckboxItem

A menu option with a checkbox.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | **required** |
| `checked` | `boolean` | - |
| `onCheckedChange` | `(checked: boolean) => void` | - |
| `disabled` | `boolean` | - |

### MenuRadioGroup

Group of mutually exclusive options.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | - |
| `onValueChange` | `(details: ValueChangeDetails) => void` | - |
| `heading` | `string` | - |

### MenuRadioItem

A single option in a radio group.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | **required** |
| `disabled` | `boolean` | - |

### MenuGroup

Groups related items.

| Prop | Type | Default |
| --- | --- | --- |
| `heading` | `string` | - |

### MenuGroupLabel

Label for a group.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | - |
| `className` | `string` | - |

### MenuSeparator

Visual divider between groups of menu items.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | - |
| `className` | `string` | - |

### MenuQuickItem

A menu option with icon-above-text layout for quick actions.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | **required** |
| `asChild` | `boolean` | - |
| `disabled` | `boolean` | - |
| `closeOnSelect` | `boolean` | - |
| `onSelect` | `VoidFunction` | - |

### MenuSub

Root element for a nested submenu. It accepts the same state and positioning props as `Menu`.

| Prop | Type | Default |
| --- | --- | --- |
| `positioning` | `PositioningOptions` | - |
| `open` | `boolean` | - |
| `defaultOpen` | `boolean` | - |
| `onOpenChange` | `(details: OpenChangeDetails) => void` | - |
| `closeOnSelect` | `boolean` | `true` |

### MenuSubTrigger

Menu item that opens its nested submenu.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | **required** |
| `disabled` | `boolean` | - |
| `asChild` | `boolean` | - |
| `className` | `string` | - |

### MenuSubContent

Holds the items rendered by a nested submenu.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | - |
| `className` | `string` | - |
| `showArrow` | `boolean` | `false` |

### MenuShortcut

Optional keyboard shortcut hint displayed next to a menu item.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

### MenuArrow

Optional arrow pointing toward the trigger.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | - |

| Prop | Type | Default |
| --- | --- | --- |
| `--arrow-background` | `string` | `var(--popover)` |
| `--arrow-size` | `string` | `calc(1.5 * var(--spacing))` |

### MenuRootProvider

Provides a Menu API created with `useMenu` to descendant components.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `UseMenuReturn` | **required** |

---

For a complete list of props, see the [Ark UI documentation](https://ark-ui.com/docs/components/menu#api-reference).
