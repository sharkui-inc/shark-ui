## Usage

```tsx
import {
  RadioGroup,
  RadioGroupItem,
} from "@/components/ui/radio-group";
```

```tsx
<RadioGroup>
  <RadioGroupItem value="item-1">{/* label */}</RadioGroupItem>
  <RadioGroupItem value="item-2">{/* label */}</RadioGroupItem>
</RadioGroup>
```

## API Reference

### RadioGroup

Root component. Manages single selection from options.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | `-` |
| `defaultValue` | `string` | `-` |
| `disabled` | `boolean` | `false` |
| `invalid` | `boolean` | `false` |
| `required` | `boolean` | `false` |
| `name` | `string` | `-` |
| `onValueChange` | `(details: ValueChangeDetails) => void` | `-` |
| `className` | `string` | `-` |

### RadioGroupItem

Single radio option. Use `value` for selection.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | `-` |
| `disabled` | `boolean` | `false` |
| `invalid` | `boolean` | `false` |
| `className` | `string` | `-` |

### RadioGroupText

Public RadioGroupText component. It forwards the underlying primitive props.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |

### RadioGroupLabel

Public RadioGroupLabel component. It forwards the underlying primitive props.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |
