## Usage

```tsx
import {
  Drawer,
  DrawerSwipeArea,
  DrawerTrigger,
  DrawerContent,
  DrawerHeader,
  DrawerTitle,
  DrawerDescription,
  DrawerBody,
  DrawerFooter,
  DrawerClose,
} from "@/components/ui/drawer";
```

```tsx
<Drawer>
  <DrawerSwipeArea />
  <DrawerTrigger />
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle />
      <DrawerDescription />
    </DrawerHeader>
    <DrawerBody>
      {/** your content here */}
    </DrawerBody>
    <DrawerFooter>
      <DrawerClose />
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

## Title & Description

`DrawerHeader` supports two usage patterns:

### Using props

Pass `title` and `description` props directly to `DrawerHeader`. 

```tsx showLineNumbers
<DrawerHeader 
  title="Allow accessory to connect?" 
  description="Do you want to allow the USB accessory to connect to this device?"
/>
```

> This approach does not require `DrawerTitle` or `DrawerDescription` components.

### Using components

Use `DrawerTitle` and `DrawerDescription` as children for more control.

```tsx showLineNumbers
<DrawerHeader>
  <DrawerTitle>Allow accessory to connect?</DrawerTitle>
  <DrawerDescription>
    Do you want to allow the USB accessory to connect to this device?
  </DrawerDescription>
</DrawerHeader>
```

## API Reference

### Drawer

Root element of the drawer.

| Prop | Type | Default |
| --- | --- | --- |
| `open` | `boolean` | `-` |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `({ open }: OpenChangeDetails) => void` | `-` |
| `onTriggerValueChange` | `(details: TriggerValueChangeDetails) => void` | `-` |
| `swipeDirection` | `"up" \| "down" \| "start" \| "end"` | `"down"` |
| `snapPoints` | `(number \| string)[]` | `[1]` |
| `defaultSnapPoint` | `number \| string \| null` | `1` |
| `snapToSequentialPoints` | `boolean` | `false` |
| `closeThreshold` | `number` | `0.25` |
| `swipeVelocityThreshold` | `number` | `700` |
| `preventDragOnScroll` | `boolean` | `true` |
| `modal` | `boolean` | `true` |
| `closeOnEscape` | `boolean` | `true` |
| `closeOnInteractOutside` | `boolean` | `true` |
| `lazyMount` | `boolean` | `true` |
| `unmountOnExit` | `boolean` | `true` |
| `hideMode` | `"display-none" \| "activity"` | `"display-none"` |
| `className` | `string` | `-` |

`swipeDirection` uses logical `start` and `end`. The DOM `data-swipe-direction` attribute is resolved to physical `left` or `right` for styling.

### DrawerTrigger

Opens the drawer on click. Use `asChild` for custom trigger elements.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `value` | `string` | `-` |
| `className` | `string` | `-` |

### DrawerSwipeArea

An invisible edge hit area that opens the drawer by swipe. Its position follows the resolved physical swipe direction.

| Prop | Type | Default |
| --- | --- | --- |
| `disabled` | `boolean` | `false` |
| `swipeDirection` | `"up" \| "down" \| "start" \| "end"` | opposite of the drawer direction |
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |

### DrawerContent

Holds the drawer panel. Supports swipe-to-close; direction inherited from root `swipeDirection`.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"default" \| "inset"` | `"default"` |
| `showBar` | `boolean` | `true` |
| `showCloseButton` | `boolean` | `false` |
| `draggable` | `boolean` | `true` |
| `className` | `string` | `-` |

| Prop | Type | Default |
| --- | --- | --- |
| `--bleed` | `string` | `--spacing(12)` |
| `--space` | `string` | `--spacing(6)` |
