## Examples

### Scroll Fade

Use `scrollFade` to fade the edges of the scroll area. The fade only appears on an axis that overflows, and only on the side you can still scroll toward. It hides at the top when you are already at the top, at the bottom when you cannot scroll further, and the same for left and right on horizontal overflow.

<ComponentPreview componentName="scroll-area" fileName="example-scroll-fade" />

### Scrollbar Gutter

Use `scrollbarGutter` to reserve padding when content overflows, so the overlay scrollbar does not cover trailing content.

## API Reference

### ScrollArea

Custom-styled scrollable region. Hides native scrollbars; preserves scroll behavior.

| Prop | Type | Default | 
| --- | --- | --- | 
| scrollFade | `boolean` | `false` | 
| scrollbarGutter | `boolean` | `false` | 
| orientation | `"both" \| "horizontal" \| "vertical"` | `"both"` |

| Attribute | Default |
| --- | --- |
| `--fade-size` | `1.5rem` |

---

For a complete list of props, see the [Ark UI documentation](https://ark-ui.com/docs/components/scroll-area#api-reference).
