## API Reference

### ScrollArea

Custom-styled scrollable region. Hides native scrollbars; preserves scroll behavior.

| Prop | Type | Default |
| --- | --- | --- | 
| `scrollFade` | `boolean` | `false` |
| `scrollbarGutter` | `boolean` | `false` |
| `fill` | `boolean` | `false` |
| `clampContentMinWidth` | `boolean` | `true` |
| `overscrollContain` | `boolean` | `false` |
| `orientation` | `"both" \| "horizontal" \| "vertical"` | `"both"` |

| Prop | Type | Default |
| --- | --- | --- |
| `--fade-size` | CSS custom property | `1.5rem` |

### ScrollAreaRootProvider

Provides a ScrollArea API created with `useScrollArea` to descendant components.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `UseScrollAreaReturn` | **required** |

### ScrollAreaScrollbar

Public ScrollAreaScrollbar component. It forwards the underlying primitive props.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | - |

---

For a complete list of props, see the [Ark UI documentation](https://ark-ui.com/docs/components/scroll-area#api-reference).
