  QrCode,

### Error correction

Set `encoding.ecc`:

- **L:** up to 7% recovery
- **M:** up to 15%
- **Q:** up to 25%
- **H:** up to 30%

## API Reference

### QrCode

Root wrapper for the QR code and optional overlay/actions.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` | `-` |
| `defaultValue` | `string` | `-` |
| `onValueChange` | `(details: ValueChangeDetails) => void` | `-` |
| `encoding` | `QrCodeGenerateOptions` | `{ ecc: "L" }` |
| `pixelSize` | `number` | `-` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `-` |

| Prop | Type | Default |
| --- | --- | --- |
| `--qr-code-size` | `string` | `--spacing(32)` |
| `--qr-code-overlay-size` | `string` | `calc(var(--qr-code-size)/4)` |

### QrCodeFrame

SVG containing the QR pattern. Scales with size.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `-` |

### QrCodeOverlay

Optional center overlay on top of the QR pattern.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `-` |

### QrCodeDownload

Downloads the QR code as an image file.

| Prop | Type | Default |
| --- | --- | --- |
| `fileName` | `string` | `-` |
| `mimeType` | `DataUrlType` | `-` |
| `quality` | `number` | `-` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `-` |

### QrCodeRootProvider

Provides a QrCode API created with `useQrCode` to descendant components.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `UseQrCodeReturn` | `required` |

---

For a complete list of props, see the [Ark UI documentation](https://ark-ui.com/docs/components/qr-code#api-reference).
