## Usage

```tsx
import { FileThumbnail } from "@/components/ui/file-thumbnail";
```

```tsx
<FileThumbnail format="PDF" />
```

The file sheet stays white in light and dark themes; only the extension badge changes tone.

When `format` is omitted, the component shows a neutral `FILE` badge.

## Supported file types

Each supported category has a fixed tone so related formats remain visually consistent.


-  <span className="size-4 rounded-sm bg-info inline-block relative top-0.5" /> **Documents and text**:  `doc`, `docm`, `docx`, `epub`, `md`, `odt`, `pages`, `rtf`, `tex`, `txt`
-  <span className="size-4 rounded-sm bg-primary inline-block relative top-0.5" /> **Images**:  `apng`, `avif`, `bmp`, `gif`, `heic`, `ico`, `jpeg`, `jpg`, `png`, `svg`, `tif`, `tiff`, `webp`
-  <span className="size-4 rounded-sm bg-destructive inline-block relative top-0.5" /> **Audio**: `aac`, `aiff`, `flac`, `m4a`, `mid`, `midi`, `mp3`, `oga`, `ogg`, `opus`, `wav`, `wma`
-  <span className="size-4 rounded-sm bg-destructive inline-block relative top-0.5" /> **Video**: `3g2`, `3gp`, `avi`, `f4v`, `flv`, `m2ts`, `m4v`, `mkv`, `mov`, `mp4`, `mpeg`, `mpg`, `ogv`, `ts`, `webm`, `wmv`
-  <span className="size-4 rounded-sm bg-destructive inline-block relative top-0.5" /> **PDF and similars**: `djv`, `djvu`, `oxps`, `pdf`, `xps`
-  <span className="size-4 rounded-sm bg-warning inline-block relative top-0.5" /> **Presentations**:  `key`, `odp`, `pot`, `potx`, `pps`, `ppsx`, `ppt`, `pptm`, `pptx`
-  <span className="size-4 rounded-sm bg-success inline-block relative top-0.5" /> **Archives**: `7z`, `bz2`, `cab`, `gz`, `rar`, `tar`, `tgz`, `xz`, `zip`, `zst`
-  <span className="size-4 rounded-sm bg-success inline-block relative top-0.5" /> **Spreadsheets**:  `csv`, `numbers`, `ods`, `tsv`, `xls`, `xlsb`, `xlsm`, `xlsx`
-  <span className="size-4 rounded-sm bg-warning inline-block relative top-0.5" /> **JavaScript and Swift**: `cjs`, `js`, `jsx`, `mjs`, `swift`
-  <span className="size-4 rounded-sm bg-info inline-block relative top-0.5" /> **TypeScript and blue source formats**: `c`, `cpp`, `cxx`, `d.ts`, `go`, `h`, `hpp`, `json`, `ts`, `tsx`
-  <span className="size-4 rounded-sm bg-success inline-block relative top-0.5" /> **Python**: `py`, `pyw`
-  <span className="size-4 rounded-sm bg-primary inline-block relative top-0.5" /> **PHP and C#**: `cs`, `php`
-  <span className="size-4 rounded-sm bg-destructive inline-block relative top-0.5" /> **Java, Ruby, Rust, and web markup**: `css`, `htm`, `html`, `java`, `rb`, `rs`, `sass`, `scss`
-  <span className="size-4 rounded-sm bg-muted-foreground inline-block relative top-0.5" /> **Unsupported**:  Any extension not listed above, such as `bin` and `exe`

## API Reference

### FileThumbnail

A visual file-format identifier.

| Prop | Type | Default |
| --- | --- | --- |
| `format` | `string` | - |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `tone` | `"default" \| "destructive" \| "info" \| "primary" \| "success" \| "warning"` | inferred from `format`, otherwise `"default"` |
| `className` | `string` | - |
