## Anatomy

```text
ChartContainer
├── ChartStyle
├── Recharts surface (BarChart, LineChart, …)
├── ChartTooltip
│   └── ChartTooltipContent
└── ChartLegend
    └── ChartLegendContent
```

## Usage

```tsx
import { Bar, BarChart } from "recharts"
import { ChartContainer, type ChartConfig } from "@/components/ui/chart"

const chartData = [{ month: "Jan", customers: 186 }, { month: "Feb", customers: 305 }]
const chartConfig = { customers: { label: "Customers", color: "var(--chart-1)" } } satisfies ChartConfig

<ChartContainer config={chartConfig} className="h-[200px] w-full max-w-sm">
  <BarChart accessibilityLayer data={chartData}>
    <Bar dataKey="customers" fill="var(--color-customers)" />
  </BarChart>
</ChartContainer>
```

## Series configuration

Add a label, color, and optional icon to each series. Use `theme` to set separate colors for light and dark mode.

```tsx
import { MonitorIcon } from "lucide-react"
import { type ChartConfig } from "@/components/ui/chart"

const chartConfig = {
  desktop: {
    label: "Desktop",
    icon: MonitorIcon,
    theme: { light: "#2563eb", dark: "#93c5fd" },
  },
} satisfies ChartConfig
```

Use `color` instead of `theme` when a series keeps the same color in both modes.

## Theming

Charts use the theme's `--chart-*` variables. See the [color palette](/docs/colors) and [styling guide](/docs/styling).

### Theme color tokens

- <div className="inline-block size-5 rounded border border-border bg-chart-1 me-2 align-middle" /> `--chart-1`: first series
- <div className="inline-block size-5 rounded border border-border bg-chart-2 me-2 align-middle" /> `--chart-2`: second series
- <div className="inline-block size-5 rounded border border-border bg-chart-3 me-2 align-middle" /> `--chart-3`: third series
- <div className="inline-block size-5 rounded border border-border bg-chart-4 me-2 align-middle" /> `--chart-4`: fourth series
- <div className="inline-block size-5 rounded border border-border bg-chart-5 me-2 align-middle" /> `--chart-5`: fifth series

Assign these variables in `chartConfig` to make series follow the active theme:

<ComponentPreview componentName="chart" fileName="example-theming-variables" />

```tsx
const chartConfig = {
  desktop: {
    label: "Desktop",
    color: "var(--chart-1)",
  },
  mobile: {
    label: "Mobile",
    color: "var(--chart-2)",
  },
} satisfies ChartConfig
```

### Light and dark colors

Set separate values when a series needs different colors in light and dark mode:

<ComponentPreview componentName="chart" fileName="example-theming-theme" />

```tsx
const chartConfig = {
  signups: {
    label: "New customers",
    theme: {
      light: "#2563eb",
      dark: "#93c5fd",
    },
  },
  target: {
    label: "Monthly target",
    theme: {
      light: "#b45309",
      dark: "#fbbf24",
    },
  },
} satisfies ChartConfig
```

### CSS color values

Use any CSS color value, including hex, HSL, and OKLCH:

```tsx
const chartConfig = {
  desktop: { label: "Desktop", color: "#2563eb" },
  mobile: { label: "Mobile", color: "hsl(150, 60%, 40%)" },
  tablet: { label: "Tablet", color: "oklch(0.68 0.16 75)" },
  laptop: { label: "Laptop", color: "var(--chart-4)" },

```

### Color chart elements

`ChartContainer` exposes `--color-*` for each config key. Use the variable on a line or area:

<ComponentPreview componentName="chart" fileName="example-theming-elements" />

For pie charts, set each slice's `fill` to its config variable:

<ComponentPreview componentName="chart" fileName="example-theming-pie" />

```tsx
const chartConfig = {
  organic: { label: "Organic search", color: "var(--chart-1)" },

  { channel: "organic", customers: 427, fill: "var(--color-organic)" },

```

### Override the palette

Override variables on `ChartContainer` to change one chart's palette:

<ComponentPreview componentName="chart" fileName="example-theming-palette" />

```tsx
<ChartContainer
  config={chartConfig}
  className="[--chart-1:var(--color-cyan-600)] [--chart-2:var(--color-amber-600)]"
>
  <BarChart data={chartData}>
    <Bar dataKey="organic" fill="var(--color-organic)" />
    <Bar dataKey="paid" fill="var(--color-paid)" />
  </BarChart>
</ChartContainer>
```

## Tooltip

Use `labelKey` and `nameKey` when the tooltip title and series names come from custom data fields:

<ComponentPreview componentName="chart" fileName="example-usage-tooltip" />

```tsx
import { type ChartConfig, ChartTooltip, ChartTooltipContent } from "@/components/ui/chart"

const chartData = [
  { browser: "chrome", visitors: 187 },
  { browser: "safari", visitors: 200 },
]

const chartConfig = {
  visitors: { label: "Visitors" },
  chrome: { label: "Chrome", color: "var(--chart-1)" },
  safari: { label: "Safari", color: "var(--chart-2)" },
} satisfies ChartConfig

<ChartTooltip content={<ChartTooltipContent labelKey="visitors" nameKey="browser" />} />
```

## Accessibility

Set `accessibilityLayer` to make chart elements keyboard accessible. Add a text summary when the data matters; color alone should not distinguish series.

```tsx
<BarChart accessibilityLayer data={chartData}>
  {/* children */}
</BarChart>
```

## API Reference

### ChartContainer

| Prop | Type | Default |
| --- | --- | --- |
| `config` | `ChartConfig` | `-` |
| `initialDimension` | `{ width: number; height: number }` | `{ width: 320, height: 200 }` |

### ChartTooltipContent

| Prop | Type | Default |
| --- | --- | --- |
| `labelKey` | `string` | `-` |
| `nameKey` | `string` | `-` |
| `indicator` | `"dot" \| "line" \| "dashed"` | `-` |
| `hideLabel` | `boolean` | `-` |
| `hideIndicator` | `boolean` | `-` |
