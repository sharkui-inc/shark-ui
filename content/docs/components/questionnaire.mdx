## Usage

```tsx
import {
  Questionnaire,
  QuestionnaireActions,
  QuestionnaireChoice,
  QuestionnaireChoices,
  QuestionnaireChoiceShortcut,
  QuestionnaireDescription,
  QuestionnaireError,
  QuestionnaireItem,
  QuestionnaireSubmit,
  QuestionnaireTitle,
} from "@/components/ui/questionnaire";
```

```tsx
const items = [{ name: "delivery", required: true }] as const;

<Questionnaire items={items} onSubmit={handleSubmit}>
  <QuestionnaireItem name="delivery">
    <QuestionnaireTitle>How should we send your order?</QuestionnaireTitle>
    <QuestionnaireDescription>Choose a delivery method.</QuestionnaireDescription>
    <QuestionnaireChoices>
      <QuestionnaireChoice value="standard">Standard delivery</QuestionnaireChoice>
      <QuestionnaireChoice value="express">Express delivery</QuestionnaireChoice>
    </QuestionnaireChoices>
    <QuestionnaireError />
  </QuestionnaireItem>
  <QuestionnaireActions>
    <QuestionnaireSubmit>Save delivery method</QuestionnaireSubmit>
  </QuestionnaireActions>
</Questionnaire>
```

## Reading answers

Answers are in the native `FormData`, including hidden steps. Empty optional answers and whitespace-only freeform answers are omitted.

```tsx
function handleSubmit(event: React.FormEvent<HTMLFormElement>) {
  event.preventDefault();
  const answers = new FormData(event.currentTarget);
  const delivery = answers.get("delivery");
  // For multiple-choice questions: answers.getAll("interests").
}
```

## Shortcuts

Set `shortcuts` to `"letters"` or `"numbers"` to enable keyboard shortcuts.

When the active question is answered, use `ArrowRight` and `ArrowLeft` to
navigate between questions while focus is outside an answer choice. Use
`ArrowUp` and `ArrowDown` to move focus between answers. Inside a radio group,
`ArrowLeft` and `ArrowRight` keep their native radio-selection behavior. Press
`Enter` on an answered answer control to continue, or `Mod+Enter` to confirm
the active question.

## API Reference

### Questionnaire

Questionnaire form root.

| Prop | Type | Default |
| --- | --- | --- |
| `items` | `readonly QuestionnaireItemDefinition[]` | **required** |
| `item` | `string` | - |
| `defaultItem` | `string` | - |
| `onItemChange` | `(details: QuestionnaireItemChangeDetails) => void` | - |
| `value` | `QuestionnaireValue` | - |
| `defaultValue` | `QuestionnaireValue` | `{}` |
| `onValueChange` | `(details: QuestionnaireValueChangeDetails) => void` | - |
| `shortcuts` | `"letters" \| "numbers"` | - |
| `onSubmit` | `FormEventHandler<HTMLFormElement>` | - |
| `className` | `string` | - |

### QuestionnaireItem

| Prop | Type | Default |
| --- | --- | --- |
| `name` | `string` | **required** |
| `id` | `string` | generated |
| `className` | `string` | - |

### QuestionnaireTitle
