## Usage

```tsx
import {
  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
  TableFooter,
} from "@/components/ui/table";
```

```tsx
<Table>
  <TableCaption />
  <TableHeader>
    <TableRow>
      <TableHead />
      <TableHead />
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell />
      <TableCell />
    </TableRow>
  </TableBody>
  <TableFooter />
</Table>
```

## Accessibility

Use `TableCaption`. Add `sr-only` to hide it visually.

```tsx showLineNumbers
<Table>
  <TableCaption className="sr-only">
    Monthly revenue by product.
  </TableCaption>
  {/* ... */}
</Table>
```

## API Reference

### Table

Scrollable wrapper around a native table. Supports striped and hover variants.

| Prop | Type | Default |
| --- | --- | --- |
| `variant` | `"plain" \| "striped"` | `"plain"` |
| `size` | `"compact" \| "comfortable" \| "default"` | `"default"` |
| `isHoverable` | `boolean` | `true` |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

| Prop | Type | Default |
| --- | --- | --- |
| `--space` | `string` | `--spacing(2)` |

### TableHeader

Table header row group.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### TableBody

Table body row group.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### TableFooter

Table footer row group for totals or summary rows.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### TableRow

A single table row.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### TableHead

Header cell for column titles.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### TableCell

Data cell for body or footer rows.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |

### TableCaption

Accessible caption describing the table.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `false` |
