## Usage

```tsx
import { Rating } from "@/components/ui/rating";
```

```tsx
<Rating aria-label="Rate your experience" />
```

For custom layouts, `Rating` also supports composing `RatingLabel` and `RatingStars`.

## API Reference

### Rating

Root component.

| Prop | Type | Default |
| --- | --- | --- |
| `allowHalf` | `boolean` | `false` |
| `count` | `number` | `5` |
| `icon` | `React.JSX.ElementType` | `StarIcon` |
| `defaultValue` | `number` | `-` |
| `value` | `number` | `-` |
| `onValueChange` | `(details: ValueChangeDetails) => void` | `-` |
| `readOnly` | `boolean` | `-` |
| `disabled` | `boolean` | `-` |
| `className` | `string` | `-` |
| `children` | `ReactNode` | `-` |

### RatingLabel

Labels the `Rating` and focuses its selected star when clicked.

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `ReactNode` | `required` |
| `className` | `string` | `-` |

### RatingStars

Renders the rating stars and hidden input.

| Prop | Type | Default |
| --- | --- | --- |
| `icon` | `React.JSX.ElementType` | `StarIcon` |
| `className` | `string` | `-` |

### RatingItem

Public RatingItem component. It forwards the underlying primitive props.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |

---

For a complete list of props, see the [Ark UI documentation](https://ark-ui.com/docs/components/rating-group#api-reference).
