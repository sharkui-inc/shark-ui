## API Reference

### PasswordInput

Password field with a built-in visibility toggle.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `placeholder` | `string` | - |
| `value` | `string` | - |
| `defaultValue` | `string` | - |
| `onChange` | `ChangeEventHandler<HTMLInputElement>` | - |
| `visibleIcon` | `React.ReactNode` | `<EyeIcon />` |
| `hiddenIcon` | `React.ReactNode` | `<EyeOffIcon />` |
| `autoComplete` | `"current-password" \| "new-password"` | `"current-password"` |
| `defaultVisible` | `boolean` | `false` |
| `visible` | `boolean` | - |
| `disabled` | `boolean` | - |
| `invalid` | `boolean` | - |
| `readOnly` | `boolean` | - |
| `required` | `boolean` | - |
| `name` | `string` | - |
| `ignorePasswordManagers` | `boolean` | - |
| `onVisibilityChange` | `(details: VisibilityChangeDetails) => void` | - |
| `className` | `string` | - |

### PasswordInputRootProvider

Provides a PasswordInput API created with `usePasswordInput` to descendant components.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `UsePasswordInputReturn` | **required** |
