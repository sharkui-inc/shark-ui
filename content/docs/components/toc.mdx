## Usage

```tsx
import {
  Toc,
  TocContent,
  TocItem,
  TocLink,
  TocList,
  TocNav,
  TocTitle,
} from "@/components/ui/toc";
```

```tsx
<Toc items={items} scrollEl={() => contentRef.current}>
  <TocContent ref={contentRef}>
    <h2 id="intro">Introduction</h2>
  </TocContent>
  <TocNav>
    <TocTitle>On this page</TocTitle>
    <TocList>
      {items.map((item) => (
        <TocItem item={item} key={item.value}>
          <TocLink href={`#${item.value}`}>{item.label}</TocLink>
        </TocItem>
      ))}
    </TocList>
  </TocNav>
</Toc>
```

Pass `scrollEl` when the document scrolls inside a container. Omit it to observe the page viewport; clicks then use native hash navigation.

## API Reference

### Toc

Root. Tracks visible headings and owns scroll behavior.

| Prop | Type | Default |
| --- | --- | --- |
| `items` | `TocItemData[]` | `[]` |
| `scrollEl` | `() => HTMLElement \| null` | - |
| `activeIds` | `string[]` | `-` |
| `defaultActiveIds` | `string[]` | `-` |
| `autoScroll` | `boolean` | `true` |
| `scrollBehavior` | `ScrollBehavior` | `"smooth"` |
| `rootMargin` | `string` | `"-20px 0px -40% 0px"` |
| `threshold` | `number \| number[]` | `0` |
| `onActiveChange` | `(details: TocActiveChangeDetails) => void` | `-` |
| `id` | `string` | `-` |
| `ids` | `Partial<{ root: string; title: string; list: string; item: (value: string) => string; link: (value: string) => string; indicator: string }>` | `-` |
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |

| Prop | Type | Default |
| --- | --- | --- |
| `--top` | CSS custom property | - |
| `--height` | CSS custom property | - |
| `--left` | CSS custom property | - |
| `--width` | CSS custom property | - |

### TocContent

Document region for headings. Observation and click-to-scroll use `scrollEl` on `Toc`, not this part.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |

### TocNav

Sticky navigation column for the list of links.

| Prop | Type | Default |
| --- | --- | --- |
| `placement` | `"left" \| "right"` | `-` |
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |

### TocTitle

Accessible title for the navigation.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |

### TocList

List container for items. Relatively positioned so `TocIndicator` can slide.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |

### TocIndicator

Optional marker that slides to span the active item(s). Place inside `TocList`.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |

### TocItem

One TOC entry. Indent follows `--depth` from the item's heading level.

| Prop | Type | Default |
| --- | --- | --- |
| `item` | `TocItemData` | **required** |
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |

| Prop | Type | Default |
| --- | --- | --- |
| `data-value` | CSS custom property | - |
| `data-active` | CSS custom property | - |
| `data-first` | CSS custom property | - |
| `data-last` | CSS custom property | - |
| `data-depth` | CSS custom property | - |

| Prop | Type | Default |
| --- | --- | --- |
| `--depth` | CSS custom property | - |

### TocLink

Anchor to a heading. Sets `aria-current="location"` when active. With `scrollEl`, clicks scroll that container and update the hash. Without it, the browser handles the hash.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `false` |
| `className` | `string` | `-` |

| Prop | Type | Default |
| --- | --- | --- |
| `data-value` | CSS custom property | - |
| `data-active` | CSS custom property | - |

### TocRootProvider

Provides a Toc API created with `useToc` to descendant components.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `UseTocReturn` | **required** |

### TocContext

Render-prop access to the surrounding component API.

| Prop | Type | Default |
| --- | --- | --- |
| `children` | `(api: unknown) => React.ReactNode` | **required** |
