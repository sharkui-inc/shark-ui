```tsx
  </TooltipContent>
</Tooltip>
```

## Choose the right primitive

Tooltip and Toggle Tooltip share visual treatment. Choose based on how people need to reach and use the content.

| Intent | Use | Why |
| --- | --- | --- |
| Name an icon-only control or add a short, optional hint | Tooltip | It opens on hover or keyboard focus, then closes automatically. Keep the content plain text and non-interactive. |
| Offer supporting details that people may open on touch, keep open, or act on | Toggle Tooltip | It uses a Popover, opened by click, Enter, or Space. Its content can receive focus and include links or buttons. |
| Give instructions required to complete a task | Visible text, a field description, or Dialog | Do not hide required information behind an overlay. |

## API Reference

### Tooltip

Root component that wraps the tooltip. Manages open state and positioning.

| Prop | Type | Default |
| --- | --- | --- |
| `positioning` | `PositioningOptions` | `{ placement: "top" }` |
| `openDelay` | `number` | `600` |
| `closeDelay` | `number` | `100` |
| `lazyMount` | `boolean` | `true` |
| `unmountOnExit` | `boolean` | `true` |
| `open` | `boolean` | `-` |
| `defaultOpen` | `boolean` | `-` |
| `onOpenChange` | `(details: OpenChangeDetails) => void` | `-` |
| `onTriggerValueChange` | `(details: TriggerValueChangeDetails) => void` | `-` |
| `disabled` | `boolean` | `-` |
| `interactive` | `boolean` | `false` |
| `closeOnClick` | `boolean` | `true` |
| `closeOnEscape` | `boolean` | `true` |
| `closeOnPointerDown` | `boolean` | `true` |
| `closeOnScroll` | `boolean` | `true` |

### TooltipTrigger

Element that shows the tooltip on hover or focus. Button by default; use `asChild` for custom elements.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `-` |
| `value` | `string` | `-` |

### TooltipContent

Tooltip content shown in a popover on hover or focus.

| Prop | Type | Default |
| --- | --- | --- |
| `className` | `string` | `-` |
| `asChild` | `boolean` | `-` |
| `showArrow` | `boolean` | `true` |

### TooltipArrow

Optional arrow pointing to the trigger. Place inside `TooltipContent`.

| Prop | Type | Default |
| --- | --- | --- |
| `asChild` | `boolean` | `-` |

| Prop | Type | Default |
| --- | --- | --- |
| `--arrow-background` | `string` | `var(--foreground)` |
| `--arrow-size` | `string` | `calc(1.5 * var(--spacing))` |

### TooltipRootProvider

Provides a Tooltip API created with `useTooltip` to descendant components.

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `UseTooltipReturn` | `required` |
