## Usage

```tsx
import { useAsyncList } from "@/hooks/use-async-list";
```

```tsx
const list = useAsyncList<User>({
  autoReload: true,

  async load({ signal }) {
    const response = await fetch("/api/users", { signal });

    if (!response.ok) throw new Error("Failed to load users");

    const items: User[] = await response.json();

    return { 
      items 
    };
  },
});
```

## API Reference

### useAsyncList

Direct export of Ark's `useAsyncList<T, C = string>`. Also exports the `UseAsyncListProps<T, C>` and `UseAsyncListReturn<T, C>` types.

| Prop | Type | Default |
| --- | --- | --- |
| `load` | `(details) => Promise<{ items: T[]; cursor?: C }>` | Required |
| `sort` | `(details) => { items: T[] } \| Promise<{ items: T[] }>` | `-` |
| `initialItems` | `T[]` | `[]` |
| `initialFilterText` | `string` | `""` |
| `initialSortDescriptor` | `{ column: keyof T; direction: "ascending" \| "descending" }` | `-` |
| `dependencies` | `(string \| number \| boolean \| null \| undefined)[]` | `[]` |
| `autoReload` | `boolean` | `false` |
| `onSuccess` | `(details: { items: T[] }) => void` | `-` |
| `onError` | `(details: { error: Error }) => void` | `-` |

`autoReload` runs the initial load; changing `dependencies` reloads the list. The cursor type is the second generic parameter, e.g. `useAsyncList<Post, number>`.

### Callback details

#### load

| Prop | Type | Default |
| --- | --- | --- |
| `signal` | `AbortSignal \| undefined` | `-` |
| `filterText` | `string` | `-` |
| `cursor` | `C \| undefined` | `-` |
| `sortDescriptor` | `{ column: keyof T; direction: "ascending" \| "descending" } \| undefined` | `-` |

Returns `{ items: T[]; cursor?: C }`.

#### sort

| Prop | Type | Default |
| --- | --- | --- |
| `items` | `T[]` | `-` |
| `descriptor` | `{ column: keyof T; direction: "ascending" \| "descending" }` | `-` |
| `filterText` | `string` | `-` |

Returns `{ items: T[] }`.
