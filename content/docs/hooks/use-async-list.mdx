## Usage

```tsx
import { useAsyncList } from "@/hooks/use-async-list";
```

```tsx
const list = useAsyncList<User>({
  autoReload: true,
  async load({ signal }) {
    const response = await fetch("/api/users", { signal });
    if (!response.ok) throw new Error("Failed to load users");
    const items: User[] = await response.json();
    return { items };
  },
});
```

Use `list.items`, `list.loading`, and `list.error` to render the result. Pass the supplied `signal` to `fetch` so requests can be canceled. `setFilterText` starts a new load immediately; the hook does not add a debounce.

The examples retain Ark's data sources: DummyJSON, JSONPlaceholder, Fake Store API, and local user fixtures. Network examples require those services to be available and show an error when a request fails.

## API Reference

### useAsyncList

A direct export of Ark's `useAsyncList<T, C = string>`. The module also exports `UseAsyncListProps<T, C>` and `UseAsyncListReturn<T, C>`.

| Prop | Type | Default |
| --- | --- | --- |
| `load` | Async function returning `{ items: T[], cursor?: C }` | Required |
| `sort` | Function returning `{ items: T[] }`, synchronously or asynchronously | - |
| `initialItems` | `T[]` | `[]` |
| `initialFilterText` | `string` | `""` |
| `initialSortDescriptor` | `{ column: keyof T; direction: "ascending" \| "descending" }` | - |
| `dependencies` | Array of strings, numbers, booleans, `null`, or `undefined` | - |
| `autoReload` | `boolean` | `false` |
| `onSuccess` | `(details: { items: T[] }) => void` | - |
| `onError` | `(details: { error: Error }) => void` | - |

`autoReload` enables the initial load. Changes to `dependencies` trigger a reload even when `autoReload` is omitted.

### Callback details

`load` receives `signal`, `filterText`, `cursor`, and `sortDescriptor`. The signal and cursor may be absent. The cursor type is the second generic parameter, for example `useAsyncList<Post, number>`.

`sort` receives `items`, `descriptor`, and `filterText`. The descriptor's `column` is a key of `T`.

### Return value

| Member | Description |
| --- | --- |
| `items` | Current items. |
| `loading`, `sorting` | Loading and local sorting states. |
| `empty`, `hasMore` | Whether the list is empty or has another cursor. |
| `error` | Error from the latest failed operation, if any. |
| `filterText`, `sortDescriptor`, `cursor` | Current filter, sorting, and pagination state. |
| `reload()` | Reload the list. |
| `loadMore()` | Append the next page when a cursor exists. |
| `sort(descriptor)` | Sort locally when a callback exists, otherwise load with the descriptor. |
| `setFilterText(text)`, `clearFilter()` | Update the filter and load matching items. |
| `abort()` | Cancel the current request. |
