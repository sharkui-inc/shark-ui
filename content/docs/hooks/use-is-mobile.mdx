## API Reference

### useIsMobile

Takes no arguments.

### Return value

| Prop | Type | Default |
| --- | --- | --- |
| `isMobile` | `boolean` | `false` |

Returns `true` when the viewport is below **768px**. The value is `false` until the hook mounts and reads the current viewport width.
