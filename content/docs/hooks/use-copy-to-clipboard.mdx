## Usage

```tsx
import { useCopyToClipboard } from "@/hooks/use-copy-to-clipboard";
```

```tsx
const clipboard = useCopyToClipboard({
  defaultValue: "https://shark-ui.com",
  timeout: 2000,
});

return (
  <Button onClick={() => clipboard.copy()}>
    {clipboard.copied ? "Copied" : "Copy"}
  </Button>
);
```

`useCopyToClipboard` re-exports Ark UI `useClipboard`. Pass `value` for controlled copy text, or `defaultValue` for uncontrolled. `timeout` clears `copied` after the delay.
