## Usage

```tsx
import { useMediaQuery, useIsMobile } from "@/hooks/use-media-query";
```

```tsx
const isDesktop = useMediaQuery("(min-width: 768px)");
const isMobile = useIsMobile();
```

## API Reference

### useMediaQuery

| Prop | Type | Default |
| --- | --- | --- |
| `query` | `string` | `required` |

### Return value

| Prop | Type | Default |
| --- | --- | --- |
| `matches` | `boolean` | `false` |

`true` when `query` matches. `false` on the server.

### useIsMobile

Shorthand for `useMediaQuery("(max-width: 767px)")`.

### Return value

| Prop | Type | Default |
| --- | --- | --- |
| `isMobile` | `boolean` | `false` |

`true` below 768px. `false` on the server.
