## Usage

```tsx
import { createListCollection } from "@ark-ui/react/collection";
import { useListSelection } from "@/hooks/use-list-selection";
```

```tsx
const selection = useListSelection({ collection, selectionMode: "multiple" });

selection.isSelected("react");
selection.toggle("react");
selection.clear();
```

Create the collection outside your component when its items are static. The hook manages selection state; your controls still provide their own labels and keyboard interactions.

## API Reference

### useListSelection

Direct export of the Ark hook. Also exports the `UseListSelectionProps<T>` and `UseListSelectionReturn` types.

| Prop | Type | Default |
| --- | --- | --- |
| `collection` | `ListCollection<T>` | Required |
| `selectionMode` | `"single" \| "multiple" \| "none"` | `"single"` |
| `deselectable` | `boolean` | `true` |
| `initialSelectedValues` | `string[]` | `[]` |
| `resetOnCollectionChange` | `boolean` | `false` |

`initialSelectedValues` defines the initial selection; it is not a controlled value. Use `setSelectedValues` to update it later. With `resetOnCollectionChange`, changing the collection clears the selection.

### Return value

| Prop | Type | Default |
| --- | --- | --- |
| `selectedValues` | `string[]` | `-` |
| `isEmpty` | `boolean` | `-` |
| `firstSelectedValue` | `string \| null` | `-` |
| `lastSelectedValue` | `string \| null` | `-` |

### Query methods

| Prop | Type | Default |
| --- | --- | --- |
| `isSelected(value)` | `(value: string \| null) => boolean` | `-` |
| `canSelect(value)` | `(value: string) => boolean` | `-` |
| `isAllSelected()` | `() => boolean` | `-` |
| `isSomeSelected()` | `() => boolean` | `-` |

### Selection methods

| Prop | Type | Default |
| --- | --- | --- |
| `select(value, forceToggle?)` | `(value: string, forceToggle?: boolean) => void` | `-` |
| `deselect(value)` | `(value: string) => void` | `-` |
| `toggle(value)` | `(value: string) => void` | `-` |
| `replace(value)` | `(value: string \| null) => void` | `-` |
| `extend(anchorValue, targetValue)` | `(anchorValue: string, targetValue: string) => void` | `-` |
| `setSelectedValues(values)` | `(values: string[]) => void` | `-` |
| `clear()` | `() => void` | `-` |
| `resetSelection()` | `() => void` | `-` |

`resetSelection()` creates a new empty selection; it does not restore `initialSelectedValues`.
