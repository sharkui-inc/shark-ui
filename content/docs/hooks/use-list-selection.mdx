## Usage

```tsx
import { createListCollection } from "@ark-ui/react/collection";
import { useListSelection } from "@/hooks/use-list-selection";
```

```tsx
const selection = useListSelection({ collection, selectionMode: "multiple" });

selection.isSelected("react");
selection.toggle("react");
selection.clear();
```

Create the collection outside your component when its items are static. The hook manages selection state; your controls still provide their own labels and keyboard interactions.

## API Reference

### useListSelection

A direct export of the Ark hook. `UseListSelectionProps<T>` and `UseListSelectionReturn` are also exported.

| Prop | Type | Default |
| --- | --- | --- |
| `collection` | `ListCollection<T>` | Required |
| `selectionMode` | `"single" \| "multiple" \| "none"` | `"single"` |
| `deselectable` | `boolean` | `true` |
| `initialSelectedValues` | `string[]` | `[]` |
| `resetOnCollectionChange` | `boolean` | `false` |

`initialSelectedValues` initializes the selection; it is not a controlled value prop. Use `setSelectedValues` for subsequent updates. Setting `resetOnCollectionChange` clears selection when the collection changes.

### Return value

| Member | Description |
| --- | --- |
| `selectedValues` | Selected values as a string array. |
| `isEmpty` | Whether no values are selected. |
| `firstSelectedValue`, `lastSelectedValue` | First and last selected values in collection order, or `null`. |
| `isSelected(value)` | Whether a value is selected. |
| `canSelect(value)` | Whether the collection allows selecting a value. |
| `isAllSelected()`, `isSomeSelected()` | Query selection across the collection. |
| `select(value, forceToggle?)` | Select using the current selection mode. |
| `deselect(value)`, `toggle(value)` | Remove or toggle a value. |
| `replace(value)` | Replace selection with one value; accepts `null`. |
| `extend(anchorValue, targetValue)` | Extend selection across a range. |
| `setSelectedValues(values)` | Set the selected values. |
| `clear()`, `resetSelection()` | Clear selection. `resetSelection()` creates a new empty selection; it does not restore `initialSelectedValues`. |
